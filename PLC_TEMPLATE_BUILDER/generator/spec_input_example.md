# spec_input_example — 文章仕様入力例

> TiSLY PLC Builder v1 / Generator  
> 人間が自然文で記述する仕様のサンプル

---

## 入力仕様（例）

```
警戒スイッチX0、非常停止X1、外周センサーX2、近接センサーX3。
警戒中は赤ライトY0を1秒点滅。
外周検知でY1点灯、Y2点滅。
近接検知でY3/Y4点灯、赤ライト高速点滅。
非常停止で全OFF。
```

---

## 仕様の読み取りポイント

| 記述 | 分類 | 抽出内容 |
|------|------|---------|
| 警戒スイッチ X0 | 入力 | X0 — モード切替 |
| 非常停止 X1 | 入力 | X1 — 安全停止 |
| 外周センサー X2 | 入力 | X2 — センサー 1 |
| 近接センサー X3 | 入力 | X3 — センサー 2 |
| 赤ライト Y0 | 出力 | Y0 — 点滅ランプ |
| Y1 点灯 / Y2 点滅 | 出力 | Y1 常灯, Y2 低速点滅 |
| Y3 / Y4 点灯 | 出力 | Y3, Y4 常灯 |
| 1秒点滅 | 点滅 | 003 BLINK SLOW |
| 高速点滅 | 点滅 | 004 BLINK FAST |
| 非常停止で全 OFF | 安全 | 002 ESTOP |
