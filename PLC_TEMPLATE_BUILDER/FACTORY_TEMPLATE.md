# FACTORY_TEMPLATE — 工場・ライン安全

> TiSLY PLC Builder v1 / Template Library v2  
> テンプレートID: `TPL-FACTORY-001`

---

## 概要

工場ライン向け安全監視システム。  
**非常停止**、**安全カーテン**、**パトライト**、**設備異常** を 001〜007 の部品で構成します。

---

## 機能要件

| 機能 | 説明 | 対応部品 |
|------|------|---------|
| 非常停止 | ライン全停止・全出力 OFF | 002 |
| 安全カーテン | 光電式安全カーテン検知保持 | 005 |
| パトライト | 待機: 黄低速点滅 / 異常: 赤高速点滅 | 003, 004, 006, 007 |
| 設備異常 | 在席センサー・異常信号のラッチ | 005, 007 |

---

## 使用部品番号一覧

| 順序 | 部品番号 | 部品名 | 本テンプレートでの役割 |
|------|---------|--------|----------------------|
| 1 | **001** | SELF HOLD | X0 ライン起動 SW → M0 稼働許可 |
| 2 | **002** | ESTOP | X1 非常停止 → 全 RST |
| 3 | **005** | SENSOR LATCH | M0 + X2 → M1 安全カーテン検知 |
| 4 | **005** | SENSOR LATCH | M0 + X3 → M2 設備異常（在席/異常信号） |
| 5 | **003** | BLINK SLOW | M0 + SM413 → Y0 黄パトライト 1s 点滅 |
| 6 | **004** | BLINK FAST | M1/M2 + SM412 → Y0 赤パトライト 高速点滅 |
| 7 | **006** | RED LIGHT PRIORITY | M1/M2 優先 / M0 低速 → M20 |
| 8 | **007** | OUTPUT CONTROL | 警報・停止出力 |

**部品セット:** `001, 002, 003, 004, 005, 005, 006, 007`

## I/O 割り当て

### 入力 (X)

| デバイス | 名称 | 部品 | 用途 |
|---------|------|------|------|
| X0 | ライン起動 SW | 001 | 稼働許可 → M0 |
| X1 | 非常停止ボタン | 002 | 全ライン停止 |
| X2 | 安全カーテン | 005 | 光電式安全検知 → M1 |
| X3 | 設備異常信号 | 005 | 在席センサー/異常接点 → M2 |

### 出力 (Y)

| デバイス | 名称 | 部品 | 動作 |
|---------|------|------|------|
| Y0 | パトライト | 003+004+006+007 | 待機: 黄1s点滅 / 異常: 赤高速点滅 |
| Y1 | ブザー | 007 | M1 ON → 警報音 |
| Y2 | 搬送停止リレー | 007 | M2 ON → 搬送機停止 |
| Y3 | 安全カーテン警告灯 | 007 | M1 ON → 常時点灯 |
| Y4 | 設備異常表示 | 007 | M2 ON → 常時点灯 |

### 内部リレー (M)

| デバイス | 名称 | 部品 |
|---------|------|------|
| M0 | 稼働許可 | 001 |
| M1 | 安全カーテン検知 | 005 |
| M2 | 設備異常 | 005 |
| M20 | Y0 パトライト制御 | 006, 007 |

## パトライト優先度

```
002 ESTOP        >  全 OFF
M1/M2（異常）    >  Y0 赤 高速点滅（004）
M0（稼働許可）   >  Y0 黄 1s 点滅（003）
停止             >  OFF
```

## 安全設計メモ

- **002 ESTOP** は PLC ソフトのみ。実設備には **ハードウェア安全回路**（安全リレー、安全 PLC）を必須配置
- 安全カーテンは EN ISO 13849 / IEC 62061 に準拠した機器を使用
- Y2 搬送停止は安全回路経由での停止を推奨（本テンプレートはデモ構成）
