# TEMPLATE_MAP — 部品番号と用途一覧

> TiSLY PLC Builder v1 / Template Library v2

---

## 部品マスタ

| 番号 | 部品ID | 部品名 | 機能概要 | ライブラリ参照 |
|------|--------|--------|---------|---------------|
| **001** | TPL-001 | **SELF HOLD** | 操作スイッチ ON を内部リレーに SET 保持。OFF 時に関連ラッチを一括 RST | `PLC_TEMPLATE_LIBRARY/001_SELF_HOLD.md` |
| **002** | TPL-002 | **ESTOP** | 非常停止入力 ON で全 M / 全 Y を強制 RST。最優先段 | `PLC_TEMPLATE_LIBRARY/002_ESTOP.md` |
| **003** | TPL-003 | **BLINK SLOW** | SM413（FX3U: M8013）による 1 秒周期点滅 | `PLC_TEMPLATE_LIBRARY/003_BLINK_SLOW.md` |
| **004** | TPL-004 | **BLINK FAST** | SM412（FX3U: M8012）による 0.1 秒周期点滅 | `PLC_TEMPLATE_LIBRARY/004_BLINK_FAST.md` |
| **005** | TPL-005 | **SENSOR LATCH** | 警戒中 + センサー ON → 警報リレー SET 保持（ラッチ） | `PLC_TEMPLATE_LIBRARY/005_SENSOR_LATCH.md` |
| **006** | TPL-006 | **RED LIGHT PRIORITY** | 高速点滅（004）> 低速点滅（003）の優先度制御 → M20 集約 | `PLC_TEMPLATE_LIBRARY/006_RED_LIGHT_PRIORITY.md` |
| **007** | TPL-007 | **OUTPUT CONTROL** | Y 出力を単一コイルで駆動。二重コイル回避 | `PLC_TEMPLATE_LIBRARY/007_OUTPUT_CONTROL.md` |

## 部品別 用途マップ

### 001 SELF HOLD

| 用途カテゴリ | 具体例 |
|-------------|--------|
| モード保持 | 警戒 ON / ARM、ライン稼働許可、監視モード |
| 入力 | セレクタスイッチ、起動スイッチ、チェックイン完了 |
| 出力先 | M0（armed / 稼働中） |

### 002 ESTOP

| 用途カテゴリ | 具体例 |
|-------------|--------|
| 安全停止 | 非常停止ボタン、緊急停止、全ライン停止 |
| 動作 | 全 M RST + 全 Y RST |
| 配置 | **必ず 001 の直後、007 より前** |

### 003 BLINK SLOW

| 用途カテゴリ | 具体例 |
|-------------|--------|
| 待機表示 | 警戒ランプ、監視中 LED、待機パトライト |
| 周期 | 1 秒（0.5s ON / 0.5s OFF） |
| 組合せ | 006 と組み合わせて Y0 低速点滅 |

### 004 BLINK FAST

| 用途カテゴリ | 具体例 |
|-------------|--------|
| 警報表示 | 侵入警告、異常警報、盗難検知 |
| 周期 | 0.1 秒（0.05s ON / 0.05s OFF） |
| 組合せ | 006 と組み合わせて Y0 高速点滅（最優先） |

### 005 SENSOR LATCH

| 用途カテゴリ | 具体例 |
|-------------|--------|
| 検知保持 | 外周検知、近接検知、ドアセンサー、PIR、安全カーテン |
| 前提条件 | M0（armed）が ON のときのみラッチ |
| 解除条件 | 001 OFF リセット / 002 ESTOP |
| 拡張 | センサー数に応じて M1, M2, M3… を複製 |

### 006 RED LIGHT PRIORITY

| 用途カテゴリ | 具体例 |
|-------------|--------|
| 優先度制御 | 同一出力への複数点滅条件の排他 |
| 優先順位 | M2（高速）> M0（低速）> OFF |
| 出力先 | M20（007 への中間リレー） |

### 007 OUTPUT CONTROL

| 用途カテゴリ | 具体例 |
|-------------|--------|
| 出力駆動 | ランプ、ブザー、リレー、照明、サイレン |
| 原則 | 1 Y = 1 OUT（二重コイル禁止） |
| パターン | M20→Y0 / M1→Y1 / M1+003→Y2 / M2→Y3,Y4 |

## デバイス命名規則

| 種別 | 範囲 | 担当部品 |
|------|------|---------|
| X0 | 開始スイッチ | 001 |
| X1 | 非常停止 | 002 |
| X2〜Xn | センサー群 | 005 |
| M0 | モード保持 | 001 |
| M1〜M9 | 警報ラッチ | 005 |
| M10〜M19 | 点滅中間（拡張用） | 003, 004 |
| M20〜M29 | 出力集約 | 006, 007 |
| Y0 | メインランプ（点滅） | 006 → 007 |
| Y1〜Yn | 個別出力 | 007 |
| SM412 / SM413 | クロック | 003, 004 |
