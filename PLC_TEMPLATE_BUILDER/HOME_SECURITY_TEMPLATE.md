# HOME_SECURITY_TEMPLATE — ホームセキュリティ

> TiSLY PLC Builder v1 / Template Library v2  
> テンプレートID: `TPL-HOME-001`  
> 由来: TiSLY_HOME_Security_DEMO（完成版）

---

## 概要

住宅向け外周・近接警備システム。001〜007 全部品を使用した **標準完成テンプレート** です。  
TiSLY_HOME_Security_DEMO プロジェクトがそのまま実装参照となります。

---

## 使用部品番号一覧

| 順序 | 部品番号 | 部品名 | 本テンプレートでの役割 |
|------|---------|--------|----------------------|
| 1 | **001** | SELF HOLD | X0 セレクタ → M0 警戒中 |
| 2 | **002** | ESTOP | X1 非常停止 → 全 RST |
| 3 | **005** | SENSOR LATCH | M0 + X2 → M1 外周警報 |
| 4 | **005** | SENSOR LATCH | M0 + X3 → M2 近接警報 |
| 5 | **003** | BLINK SLOW | M0 + SM413 → 警戒時 Y0 低速点滅 |
| 6 | **004** | BLINK FAST | M2 + SM412 → 近接時 Y0 高速点滅 |
| 7 | **006** | RED LIGHT PRIORITY | M2 優先 / M0 低速 → M20 |
| 8 | **007** | OUTPUT CONTROL | M20→Y0, M1→Y1/Y2, M2→Y3/Y4 |

**部品セット:** `001, 002, 003, 004, 005, 005, 006, 007`

---

## テンプレート構成図

```
┌─────────────────────────────────────────────────────────────────┐
│              HOME SECURITY TEMPLATE（完成版）                     │
└─────────────────────────────────────────────────────────────────┘

  [001] SELF HOLD
  X0 + /X1 ──→ SET M0
  /X0 ──→ RST M0/M1/M2
        │
        ▼
  [002] ESTOP
  X1 ──→ RST M0/M1/M2 + Y0〜Y4
        │
        ▼
  [005] SENSOR LATCH ×2
  M0 + X2 ──→ SET M1（外周）
  M0 + X3 ──→ SET M2（近接）
        │
        ├──────────────────────────┐
        ▼                          ▼
  [003] BLINK SLOW            [004] BLINK FAST
  M0 + SM413                  M2 + SM412
        │                          │
        └──────────┬───────────────┘
                   ▼
        [006] RED LIGHT PRIORITY
        M2 優先 / M0 低速 → M20
                   │
                   ▼
        [007] OUTPUT CONTROL
        M20 → Y0（赤ライト）
        M1  → Y1（常灯）, Y2（1s点滅）
        M2  → Y3, Y4（常灯）
```

---

## I/O 割り当て

### 入力 (X)

| デバイス | 名称 | 部品 | 用途 |
|---------|------|------|------|
| X0 | セレクタスイッチ | 001 | 警戒 ON/OFF |
| X1 | 非常停止ボタン | 002 | 全停止 |
| X2 | ビームセンサー1 | 005 | 外周検知 |
| X3 | ビームセンサー2 | 005 | 近接検知 |

### 出力 (Y)

| デバイス | 名称 | 部品 | 動作 |
|---------|------|------|------|
| Y0 | 赤ライト (24V) | 003+004+006+007 | 警戒: 1s点滅 / 近接: 0.1s点滅 |
| Y1 | 白ライト1 (100V) | 007 | 外周警報: 常時点灯 |
| Y2 | 白ライト2 (100V) | 003+007 | 外周警報: 1s点滅 |
| Y3 | 白ライト3 (100V) | 007 | 近接警報: 常時点灯 |
| Y4 | 白ライト4 (100V) | 007 | 近接警報: 常時点灯 |

### 内部リレー (M)

| デバイス | 名称 | 部品 |
|---------|------|------|
| M0 | 警戒中 | 001 |
| M1 | 外周警報保持 | 005 |
| M2 | 近接警報保持 | 005 |
| M20 | Y0 制御 | 006, 007 |

---

## 状態遷移

```
        X0 ON
  ┌──────────────┐
  │              ▼
停止 ──────→ 警戒中(M0) ──X2──→ 外周警報(M1)
  ▲              │                  │
  │              └──X3──→ 近接警報(M2) ←┘
  │                         │
  X0 OFF / X1 ESTOP         │
  └─────────────────────────┘
```

---

## 出力状態表

| 状態 | Y0 赤 | Y1 | Y2 | Y3 | Y4 |
|------|-------|----|----|----|-----|
| 停止 (X0 OFF) | OFF | OFF | OFF | OFF | OFF |
| 警戒中 (M0) | 1s 点滅 | OFF | OFF | OFF | OFF |
| 外周警報 (M1) | 1s 点滅* | ON | 1s 点滅 | OFF | OFF |
| 近接警報 (M2) | **0.1s 点滅** | ※ | ※ | ON | ON |
| 非常停止 (X1) | OFF | OFF | OFF | OFF | OFF |

\* M2 ON 時は 006 により高速点滅が最優先。
