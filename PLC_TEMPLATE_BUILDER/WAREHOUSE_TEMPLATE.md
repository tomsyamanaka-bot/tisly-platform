# WAREHOUSE_TEMPLATE — 倉庫・在庫監視

> TiSLY PLC Builder v1 / Template Library v2  
> テンプレートID: `TPL-WAREHOUSE-001`

---

## 概要

倉庫・物流施設向け監視システム。  
**シャッター監視**、**侵入検知**、**照明連動** を 001〜007 の部品で構成します。

---

## 機能要件

| 機能 | 説明 | 対応部品 |
|------|------|---------|
| シャッター監視 | シャッター開閉状態の検知保持 | 005 |
| 侵入検知 | 倉庫内 PIR / ビームセンサー | 005 |
| 照明連動 | 警報・監視状態に応じた照明 ON/OFF | 007 |

---

## 使用部品番号一覧

| 順序 | 部品番号 | 部品名 | 本テンプレートでの役割 |
|------|---------|--------|----------------------|
| 1 | **001** | SELF HOLD | X0 監視開始 SW → M0 在庫監視中 |
| 2 | **002** | ESTOP | X1 非常停止 → 全 RST |
| 3 | **005** | SENSOR LATCH | M0 + X2 → M1 シャッター異常（開放検知） |
| 4 | **005** | SENSOR LATCH | M0 + X3 → M2 侵入検知（PIR/ビーム） |
| 5 | **003** | BLINK SLOW | M0 + SM413 → Y0 監視灯 1s 点滅 |
| 6 | **004** | BLINK FAST | M1/M2 + SM412 → Y0 警報高速点滅 |
| 7 | **006** | RED LIGHT PRIORITY | M1/M2 優先 / M0 低速 → M20 |
| 8 | **007** | OUTPUT CONTROL | 照明・警告出力 |

**部品セット:** `001, 002, 003, 004, 005, 005, 006, 007`

## I/O 割り当て

### 入力 (X)

| デバイス | 名称 | 部品 | 用途 |
|---------|------|------|------|
| X0 | 監視開始 SW | 001 | 在庫監視モード → M0 |
| X1 | 非常停止ボタン | 002 | 全停止 |
| X2 | シャッター開閉センサー | 005 | 閉じていない/異常開 → M1 |
| X3 | 侵入検知センサー | 005 | PIR / ビーム → M2 |

### 出力 (Y)

| デバイス | 名称 | 部品 | 動作 |
|---------|------|------|------|
| Y0 | 監視/警報ランプ | 003+004+006+007 | 監視: 1s点滅 / 警報: 高速点滅 |
| Y1 | シャッター警告灯 | 007 | M1 ON → 常時点灯 |
| Y2 | 倉庫照明（シャッター連動） | 007 | M1 ON → 照明 ON |
| Y3 | 侵入警告灯 | 007 | M2 ON → 常時点灯 |
| Y4 | 倉庫照明（侵入連動） | 007 | M2 ON → 照明 ON |

### 内部リレー (M)

| デバイス | 名称 | 部品 |
|---------|------|------|
| M0 | 在庫監視中 | 001 |
| M1 | シャッター異常 | 005 |
| M2 | 侵入警報 | 005 |
| M20 | Y0 制御 | 006, 007 |

---

## 照明連動ロジック

```
シャッター異常 (M1)
    ├─ Y1 警告灯 ON
    └─ Y2 倉庫照明 ON  ← 異常確認のため自動点灯

侵入検知 (M2)
    ├─ Y3 警告灯 ON
    └─ Y4 倉庫照明 ON  ← 侵入確認のため自動点灯

監視中 (M0) のみ
    └─ Y0 監視灯 1s 点滅（003）
```

---

## 状態遷移

```
監視開始(X0) ──→ 在庫監視(M0) ──監視灯点滅──→ 通常監視
                      │
                 X2(シャッター) ──→ M1 ──→ 警告灯+照明ON
                      │
                 X3(侵入) ──→ M2 ──→ 警告灯+照明ON+高速点滅
                      │
X0 OFF / X1 ESTOP ◄───┴──────────────────────────
```
