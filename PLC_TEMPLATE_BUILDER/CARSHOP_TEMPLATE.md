# CARSHOP_TEMPLATE — 車屋・夜間警備

> TiSLY PLC Builder v1 / Template Library v2  
> テンプレートID: `TPL-CARSHOP-001`

---

## 概要

カーショップ・ディーラー向け夜間警備システム。  
**展示車監視**、**外周検知**、**夜間警備** を 001〜007 の部品で構成します。

---

## 機能要件

| 機能 | 説明 | 対応部品 |
|------|------|---------|
| 展示車監視 | 展示場内 PIR / 近接センサーで車両周辺を監視 | 005 |
| 外周検知 | 敷地外周ビーム・フェンスセンサー | 005 |
| 夜間警備 | 警備セット後の監視モード + 看板赤灯点滅 | 001, 003, 004, 006 |

---

## 使用部品番号一覧

| 順序 | 部品番号 | 部品名 | 本テンプレートでの役割 |
|------|---------|--------|----------------------|
| 1 | **001** | SELF HOLD | X0 警備セット SW → M0 夜間警備中 |
| 2 | **002** | ESTOP | X1 非常停止 → 全 RST |
| 3 | **005** | SENSOR LATCH | M0 + X2 → M1 外周検知（フェンス/ビーム） |
| 4 | **005** | SENSOR LATCH | M0 + X3 → M2 展示車監視（店内 PIR） |
| 5 | **003** | BLINK SLOW | M0 + SM413 → Y0 看板赤灯 1s 点滅 |
| 6 | **004** | BLINK FAST | M1/M2 + SM412 → Y0 高速点滅（盗難警告） |
| 7 | **006** | RED LIGHT PRIORITY | M1/M2 優先 / M0 低速 → M20 |
| 8 | **007** | OUTPUT CONTROL | 照明・サイレン出力 |

**部品セット:** `001, 002, 003, 004, 005, 005, 006, 007`

## I/O 割り当て

### 入力 (X)

| デバイス | 名称 | 部品 | 用途 |
|---------|------|------|------|
| X0 | 警備セット SW | 001 | 夜間警備開始 → M0 |
| X1 | 非常停止ボタン | 002 | 全停止 |
| X2 | 外周ビーム/フェンス | 005 | 敷地外周検知 → M1 |
| X3 | 店内 PIR（展示車監視） | 005 | 展示場内人感 → M2 |

### 出力 (Y)

| デバイス | 名称 | 部品 | 動作 |
|---------|------|------|------|
| Y0 | 看板赤灯 | 003+004+006+007 | 警備中: 1s点滅 / 盗難: 高速点滅 |
| Y1 | 外部照明 | 007 | M1 ON → 常時点灯 |
| Y2 | サイレン | 007 | M2 ON → 常時 ON |
| Y3 | 外周警告灯 | 007 | M1 ON → 常時点灯 |
| Y4 | 店内警告灯 | 007 | M2 ON → 常時点灯 |

## 夜間警備フロー

```
営業終了
    │
    ▼
警備セット (X0 ON) ──→ M0 夜間警備中
    │
    ├─ Y0 看板赤灯 1s 点滅（003）← 「警備中」表示
    │
    ├─ X2 外周検知 ──→ M1 ──→ 外部照明+外周警告灯
    │                         Y0 高速点滅（004+006）
    │
    └─ X3 店内 PIR ──→ M2 ──→ サイレン+店内警告灯
                              Y0 高速点滅（004+006）

朝：警備解除 (X0 OFF) ──→ 全 RST
```

---

## 状態遷移

```
警備セット(X0) ──→ 夜間警備(M0) ──看板赤灯点滅──→ 監視中
                      │
                 X2(外周) ──→ M1 ──→ 外部照明+警告
                      │
                 X3(店内) ──→ M2 ──→ サイレン+警告
                      │
X0 OFF / X1 ESTOP ◄───┴──────────────────────────
```

## 出力状態表

| 状態 | Y0 看板赤 | Y1 外部照明 | Y2 サイレン | Y3 外周灯 | Y4 店内灯 |
|------|----------|------------|------------|----------|----------|
| 停止 | OFF | OFF | OFF | OFF | OFF |
| 警備中 (M0) | 1s 点滅 | OFF | OFF | OFF | OFF |
| 外周警報 (M1) | 高速点滅 | ON | OFF | ON | OFF |
| 店内警報 (M2) | 高速点滅 | ※ | ON | OFF | ON |
| 非常停止 (X1) | OFF | OFF | OFF | OFF | OFF |

※ M1 と M2 は独立保持。両方 ON の場合は各出力が OR 的に重なる。
