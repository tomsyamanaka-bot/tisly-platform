# BUILDER_RULES — 仕様書からの自動選定ルール

> TiSLY PLC Builder v1  
> 自然文仕様 → 部品番号（001〜007）+ 業種テンプレート

---

## 選定フロー

```
1. 仕様文をトークン化（キーワード抽出）
2. 下表「キーワード → 部品」で部品番号を追加
3. 業種キーワードでテンプレートを決定
4. 005 の使用回数 = センサー種別の数
5. 003/004/006 は点滅出力が必要な場合に追加
6. 001 + 002 + 007 は原則必須（安全系を除く最小構成）
```

---

## キーワード → 部品 対応表

### 001 SELF HOLD

| 仕様キーワード（いずれか一致） | 選定部品 |
|------------------------------|---------|
| 警戒、警備、ARM、監視モード、稼働、起動、セット、ON/OFF切替 | **001** |
| セレクタ、運転許可、チェックイン、夜間モード、清掃モード切替 | **001** |

```
警戒ON切替
    ↓
001 SELF HOLD
```

| 仕様キーワード（いずれか一致） | 選定部品 |
|------------------------------|---------|
| 非常停止、緊急停止、ESTOP、E-STOP、全停止、安全停止 | **002** |

### 005 SENSOR LATCH

| 仕様キーワード（いずれか一致） | 選定部品 | 備考 |
|------------------------------|---------|------|
| 侵入検知、外周検知、近接検知、ビームセンサー | **005** | 1 キーワード = 1 チャンネル |
| ドアセンサー、PIR、赤外線、人感、窓センサー | **005** | |
| 安全カーテン、在席センサー、光電センサー | **005** | |
| シャッター、扉開閉、温度異常、煙感知 | **005** | |
| ガラス破損、展示車監視、人数カウント | **005** | |

```
侵入検知
    ↓
```

## 業種キーワード → テンプレート

| 仕様キーワード（いずれか一致） | テンプレート |
|------------------------------|-------------|
| ホーム、住宅、自宅、セキュリティ、HOME | HOME_SECURITY |
| 民泊、ゲストハウス、MINPAKU、宿泊、Airbnb | MINPAKU |
| 工場、ライン、生産、FACTORY、製造 | FACTORY |
| 倉庫、在庫、WAREHOUSE、物流、保管 | WAREHOUSE |
| 車屋、カーショップ、CARSHOP、展示車、ディーラー | CARSHOP |

**ルール:** 複数一致時は **より具体的なキーワード** を優先（例: 「民泊のホームセキュリティ」→ MINPAKU）。

## 複合仕様の選定例

### 例 1：ホームセキュリティ

**入力仕様:**

> ホームセキュリティ。セレクタで警戒ON。外周ビームと近接ビーム。
> 警戒中は赤ランプ1秒点滅。近接検知時は高速点滅。白ライト4灯。
> 非常停止あり。

**選定結果:**

| キーワード | 部品 |
|-----------|------|
| 警戒ON / セレクタ | 001 |
| 非常停止 | 002 |
| 外周ビーム / 近接ビーム | 005 ×2 |
| 1秒点滅 / 警戒ランプ | 003 |
| 高速点滅 / 近接検知 | 004 |
| 003+004 同時 | 006（自動） |
| 白ライト / 出力 | 007 |

**テンプレート:** HOME_SECURITY  
**部品一覧:** `001, 002, 003, 004, 005, 005, 006, 007`

---

### 例 2：民泊

**入力仕様:**

> 民泊。チェックイン後監視開始。玄関ドアとPIR赤外線。
> 満室表示と清掃モード切替。侵入時サイレン。

**選定結果:**

| キーワード | 部品 |
|-----------|------|
| 監視開始 / チェックイン | 001 |
| 玄関ドア / PIR | 005 ×2 |
| 監視中点滅 | 003 |
| 侵入 / サイレン | 004, 007 |
| 003+004 | 006 |
| 非常停止（暗黙必須） | 002 |

**テンプレート:** MINPAKU  
**部品一覧:** `001, 002, 003, 004, 005, 005, 006, 007`

---

### 例 3：工場

**入力仕様:**

> 工場ライン。起動スイッチ。非常停止。安全カーテンと在席センサー。
> パトライト黄点滅。異常時赤高速点滅。搬送停止出力。

**選定結果:**

| キーワード | 部品 |
|-----------|------|
| 起動スイッチ | 001 |
| 非常停止 | 002 |
| 安全カーテン / 在席センサー | 005 ×2 |
| 黄点滅 / 待機 | 003 |
| 異常 / 高速点滅 | 004 |
| 003+004 | 006 |
| 搬送停止 / 出力 | 007 |

**テンプレート:** FACTORY  
**部品一覧:** `001, 002, 003, 004, 005, 005, 006, 007`

## 必須・自動追加ルール（まとめ）

| 条件 | 動作 |
|------|------|
| モード切替・警戒・起動が含まれる | 001 を追加 |
| 非常停止・緊急停止が含まれる | 002 を追加 |
| 実設備（安全規格対象） | 002 を **暗黙必須** で追加 |
| センサー入力が N 種類 | 005 を N 個追加 |
| 点滅出力が 1 種類のみ | 003 **または** 004 |
| 低速+高速点滅が両方 | 003 + 004 + **006 自動** |
| Y 出力が 1 つ以上 | 007 を追加 |

```yaml

  - "001 SELF HOLD"
  - "002 ESTOP"
  - "003 BLINK SLOW"
  - "004 BLINK FAST"
  - "005 SENSOR LATCH (X2 → M1)"
  - "005 SENSOR LATCH (X3 → M2)"
  - "006 RED LIGHT PRIORITY"
  - "007 OUTPUT CONTROL"
io_ref: HOME_SECURITY_TEMPLATE.md
library: ../PLC_TEMPLATE_LIBRARY/
```

## 除外ルール

| 条件 | 除外 |
|------|------|
| 常時点灯のみ（点滅不要） | 003, 004, 006 を除外 |
| センサーなし（表示のみ） | 005 を除外 |
| 出力なし（内部処理のみ） | 007 を除外（非推奨構成） |
| 非常停止なし（デモ限定） | 002 を除外可（**実設備では禁止**） |
