# KEYWORD_ENGINE — キーワード解析エンジン

> TiSLY PLC Builder v2.5 / Engine  
> 機能1: 文章解析 — キーワード → 部品番号（001〜007）自動選定

---

## 目的

`INPUT_SPEC.md` で正規化されたテキスト行から、  
`BUILDER_RULES.md`（v1）を拡張した **決定論的キーワードマッチング** で部品を選定する。

---

## 解析フロー

```
各行テキスト
    │
    ▼
キーワード辞書照合（部分一致・優先度付き）
    │
    ▼
部品番号セット（重複排除・順序付け）
    │
    ▼
自動追加ルール適用
    │
    ▼
parts[] 確定
```

## キーワード辞書

### 001 SELF HOLD

| 優先度 | キーワード |
|:------:|-----------|
| 1 | 警戒スイッチ、警戒、警備、ARM |
| 2 | セレクタ、起動、セット、監視モード |
| 3 | チェックイン、夜間モード、清掃モード |

```
「警戒スイッチ」→ 001
```

---

### 002 ESTOP

| 優先度 | キーワード |
|:------:|-----------|
| 1 | 非常停止、緊急停止、ESTOP、E-STOP |
| 2 | 非常ボタン、安全停止、全停止 |

```
「非常停止」→ 002（必須）
```

---

### 003 BLINK SLOW

| 優先度 | キーワード |
|:------:|-----------|
| 1 | 1秒点滅、低速点滅、SM413 |
| 2 | 警戒ランプ、監視中、待機表示 |
| 3 | 点滅（単独時は 003 を優先） |

```
「赤灯点滅」→ 003 + 007
```

---

### 004 BLINK FAST

| 優先度 | キーワード |
|:------:|-----------|
| 1 | 高速点滅、0.1秒点滅、SM412 |
| 2 | 異常警報、侵入警告、盗難 |
| 3 | 近接検知時点滅（HOME_SECURITY 標準動作） |

```
近接センサー + 赤灯 → 004 も自動選定（HOME_SECURITY テンプレート連動）
```

---

### 005 SENSOR LATCH

| 優先度 | キーワード |
|:------:|-----------|
| 1 | 外周センサー、近接センサー、ビームセンサー |
| 2 | ドアセンサー、PIR、人感、窓センサー |
| 3 | 安全カーテン、光電センサー、侵入検知 |

```
「外周センサー」→ 005（チャンネル 1）
「近接センサー」→ 005（チャンネル 2）
```

**ルール:** 独立センサー行ごとに 005 を 1 つ追加。同一 M 番号は共有禁止。

---

### 006 RED LIGHT PRIORITY

| 優先度 | キーワード |
|:------:|-----------|
| 1 | （003 AND 004 が両方選定された場合）自動追加 |
| 2 | 優先度、高速優先、同一ランプ複数条件 |

```
003 + 004 同時 → 006 自動必須
```

---

### 007 OUTPUT CONTROL

| 優先度 | キーワード |
|:------:|-----------|
| 1 | 赤灯、白灯、ランプ、照明、ブザー |
| 2 | Y0、出力、リレー、サイレン |
| 3 | `N回路`（例: 白灯4回路 → Y×4） |

```
「白灯4回路」→ 007（Y 出力 4 チャンネル）
```

## 標準入力例の解析

### 入力

```
警戒スイッチ
非常停止
外周センサー
近接センサー
赤灯点滅
白灯4回路
```

### 行別マッチ結果

| 行 | マッチ部品 | 根拠キーワード |
|----|-----------|--------------|
| 警戒スイッチ | **001** | 警戒, スイッチ |
| 非常停止 | **002** | 非常停止 |
| 外周センサー | **005** | 外周, センサー |
| 近接センサー | **005** | 近接, センサー |
| 赤灯点滅 | **003**, **007** | 点滅, 赤灯 |
| 白灯4回路 | **007** | 白灯, 4回路 |

### 自動追加

| 条件 | 追加部品 |
|------|---------|
| 003 選定済 + 近接センサーあり | **004**（近接時高速点滅） |
| 003 + 004 両方 | **006** |

### 最終部品リスト

```
001
002
003
004
005  （外周）
005  （近接）
006
007
```

## 業種テンプレート選定

| キーワード | テンプレート |
|-----------|-------------|
| ホーム、住宅、セキュリティ | HOME_SECURITY |
| 民泊、ゲストハウス | MINPAKU |
| 工場、ライン | FACTORY |
| 倉庫、在庫 | WAREHOUSE |
| 車屋、展示車 | CARSHOP |

**デフォルト:** 上記不一致時は `HOME_SECURITY` を適用。

## 出力フォーマット

```yaml
keyword_engine_result:
  template: HOME_SECURITY
  parts:
    - id: "001"
      name: SELF HOLD
      trigger: "警戒スイッチ"
    - id: "002"
      name: ESTOP
      trigger: "非常停止"
    - id: "003"
      name: BLINK SLOW
      trigger: "赤灯点滅"
    - id: "004"
      name: BLINK FAST
      trigger: "近接センサー（自動）"
    - id: "005"
      name: SENSOR LATCH
      trigger: "外周センサー"
      channel: 1
    - id: "005"
      name: SENSOR LATCH
      trigger: "近接センサー"
      channel: 2
    - id: "006"
      name: RED LIGHT PRIORITY
      trigger: "003+004 自動"
    - id: "007"
      name: OUTPUT CONTROL
      trigger: "赤灯点滅, 白灯4回路"
  assembly_order: [001, 002, 005, 005, 003, 004, 006, 007]
```
