# DEVICE_ALLOCATOR — 自動デバイス割付エンジン

> TiSLY PLC Builder v2.5 / Engine  
> 機能2: 自動デバイス割付 — X / Y / M の自動採番

---

## 目的

`KEYWORD_ENGINE` で選定された部品に対し、  
三菱 FX5UJ（GX Works3）向けのデバイス番号を **競合なく自動割り当て** する。

---

## 割付ゾーン

| 種別 | 開始 | 用途 | 担当部品 |
|------|------|------|---------|
| **X** | X0〜 | 入力接点 | 001, 002, 005 |
| **Y** | Y0〜 | 出力コイル | 007 |
| **M** | M0〜 | 内部リレー | 001, 005, 006, 007 |
| **SM** | SM412, SM413 | クロック（固定） | 003, 004 |

---

## 自動採番ルール

### X 入力（X0〜）

| 順序 | 部品 | デフォルト | 名称例 |
|:----:|------|-----------|--------|
| 1 | 001 SELF HOLD | **X0** | 警戒スイッチ |
| 2 | 002 ESTOP | **X1** | 非常停止 |
| 3〜 | 005 SENSOR LATCH ×n | **X2, X3, …** | 外周, 近接, … |

```
X0  警戒
X1  非常停止
X2  外周センサー
X3  近接センサー
```

---

### M 内部リレー（M0〜）

| 番号帯 | 用途 | 担当部品 | 命名例 |
|--------|------|---------|--------|
| **M0** | モード保持（警戒中） | 001 | 警戒 |
| **M1〜M9** | センサーラッチ | 005 | 外周→M1, 近接→M2 |
| **M10〜M19** | 点滅中間（拡張用） | 003, 004 | — |
| **M20〜M29** | 出力集約 | 006, 007 | 点滅→M20 |

#### 標準割付（HOME_SECURITY）

| デバイス | 名称 | 由来 |
|---------|------|------|
| **M0** | 警戒中 | 001 — 「警戒」 |
| **M1** | 外周警報保持 | 005 — 「外周」 |
| **M2** | 近接警報保持 | 005 — 「近接」 |
| **M20** | Y0 出力集約 | 006 — 「点滅」 |

```
警戒  → M0
外周  → M1
近接  → M2
点滅  → M20
```

---

### Y 出力（Y0〜）

| 順序 | 用途 | デフォルト | 名称例 |
|:----:|------|-----------|--------|
| 1 | メインランプ（点滅対象） | **Y0** | 赤灯 |
| 2〜 | 個別出力 | **Y1, Y2, …** | 白灯1, 白灯2, … |

#### 白灯 N 回路の展開

```
「白灯4回路」→ Y1, Y2, Y3, Y4
```

| デバイス | 名称 | 駆動条件（HOME_SECURITY） |
|---------|------|--------------------------|
| Y0 | 赤灯 | M20（006 経由点滅） |
| Y1 | 白灯1 | M1 常灯 |
| Y2 | 白灯2 | M1 + SM413 点滅 |
| Y3 | 白灯3 | M2 常灯 |
| Y4 | 白灯4 | M2 常灯 |

---

## 割付アルゴリズム

```
1. 固定デバイスを予約
   X0 ← 001, X1 ← 002, M0 ← 001, SM412/SM413 ← 固定

2. 005 チャンネル数分ループ
   X_counter ← 2, M_counter ← 1
   各センサー: X[X_counter] ← 入力, M[M_counter] ← ラッチ
   counter++

3. 007 出力数をカウント
   Y0 ← 点滅ランプ（存在時）
   Y1〜Yn ← 残り出力

4. 006 必要時
   M20 ← 最初の点滅集約リレー（M20〜M29 から空きを検索）

5. 割付表を出力
```

## プレースホルダ置換

`PLC_TEMPLATE_LIBRARY/` の部品 IL は以下のプレースホルダを使用する。  
Allocator が確定した値で置換する。

| プレースホルダ | 例 |
|---------------|-----|
| `{X_ARM}` | X0 |
| `{X_ESTOP}` | X1 |
| `{X_SENSOR_n}` | X2, X3 |
| `{M_ARM}` | M0 |
| `{M_LATCH_n}` | M1, M2 |
| `{M_OUT_AGG}` | M20 |
| `{Y_MAIN}` | Y0 |
| `{Y_n}` | Y1〜Y4 |

---

## 競合回避

| ルール | 内容 |
|--------|------|
| X 重複禁止 | 同一 X 番号を 2 部品に割り当てない |
| M 重複禁止 | 005 チャンネルごとに M1, M2… を連番 |
| Y 重複禁止 | 1 Y = 1 OUT（007 原則） |
| M20 予約 | 006 使用時は M20〜M29 を集約用に確保 |
| SM 固定 | SM412 / SM413 のみ。M8012 / M8013 禁止 |

## 出力フォーマット

```yaml
device_allocation:
  inputs:
    X0: { name: 警戒スイッチ, part: "001" }
    X1: { name: 非常停止, part: "002" }
    X2: { name: 外周センサー, part: "005", latch: M1 }
    X3: { name: 近接センサー, part: "005", latch: M2 }
  relays:
    M0: { name: 警戒中, part: "001" }
    M1: { name: 外周警報, part: "005" }
    M2: { name: 近接警報, part: "005" }
    M20: { name: 赤灯制御, part: "006" }
  outputs:
    Y0: { name: 赤灯, part: "007", via: M20 }
    Y1: { name: 白灯1, part: "007", drive: M1 }
    Y2: { name: 白灯2, part: "007", drive: "M1+SM413" }
    Y3: { name: 白灯3, part: "007", drive: M2 }
    Y4: { name: 白灯4, part: "007", drive: M2 }
  clocks:
    SM412: { period: "0.1s", part: "004" }
    SM413: { period: "1.0s", part: "003" }
```
