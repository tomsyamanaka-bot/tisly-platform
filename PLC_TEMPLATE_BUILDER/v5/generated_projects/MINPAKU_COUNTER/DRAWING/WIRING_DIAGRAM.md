# WIRING_DIAGRAM — TiSLY PLC Builder v5.0

> TiSLY株式会社 / MINPAKU_COUNTER デモ案件 — ASCII 配線図

---

## 入力回路（24V DC）

```
X0 ---- チェックイン完了
X1 ---- E-STOP
X2 ---- 赤外線ビーム
X3 ---- PIRセンサー
X4 ---- 清掃モード
```

---

## 出力回路

```
Y0 ---- 満室表示
Y1 ---- 人数カウント1
Y2 ---- 人数カウント2
Y3 ---- 人数カウント3
Y4 ---- 人数カウント4
```

---

## 配線メモ

| 項目 | 内容 |
|------|------|
| PLC | FX5UJ-24MR/ES |
| 入力電源 | DC24V（コモン COM） |
| 赤外線 / PIR | センサー出力 a接点 → X 入力 |
| マグネット | ドアセンサー b接点 → X 入力 |
| 非常停止 | b接点 NC。OFF で全出力停止 |
| パトライト | Y0 赤 24V 直結（黄/緑は拡張時） |
| ブザー | 24V ブザー直結 |
| 白灯 | 中継リレー経由 AC100V |
