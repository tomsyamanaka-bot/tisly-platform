# TiSLY PLC Builder v5.15 — TiSLY Auto Node-RED Flow Generator 設計書

**ステータス**: 設計（未実装）  
**前提**: v5.14 TiSLY Integration Engine（`TISLY/NODE_RED_CONFIG.json` 生成済み）

---

## 1. 目的

v5.14 で生成した `NODE_RED_CONFIG.json` / `DEVICE_MAP.csv` / `MQTT_TOPICS.md` を入力とし、  
案件ごとに **Node-RED `flows.json`** を自動生成する。

```
案件情報 → PLC設計 → TiSLY設定 → ESP設定 → MQTT設定 → Node-RED設定
    → 【v5.15: Node-RED flows.json 自動生成】 → 見積 → 現調報告書
```

---

## 2. 出力

```
generated_projects/<案件名>/
└── TISLY/
    ├── ... (v5.14 既存 5 ファイル)
    └── flows.json          ← v5.15 新規
```

---

## 3. 入力

| ソース | 用途 |
|--------|------|
| `TISLY/NODE_RED_CONFIG.json` | alarm/motion/contact/output 定義 |
| `TISLY/MQTT_TOPICS.md` | トピック一覧 |

## 4. flows.json 構成（案）

### 4.1 サブフロー

| ID | 名称 | 役割 |
|----|------|------|
| `sf-mqtt-in` | MQTT Input Hub | broker 接続・トピック購読 |
| `sf-alarm` | Alarm Handler | ALARM 入力 → Push / ログ |
| `sf-motion` | Motion Handler | MOTION 入力 → 条件付き通知 |
| `sf-output` | Output Control | UI / API → PLC 出力 MQTT |
| `sf-push` | Push Notification | Firebase / Webhook |

### 4.2 ノードテンプレート

```json
{
  "type": "mqtt in",
  "topic": "tisly/device/{device_id}/alarm",
  "qos": "1",
  "broker": "tisly-mqtt-broker"
}
```

```json
{
  "type": "function",
  "name": "Alarm to Push",
  "func": "// generated by TiSLY PLC Builder v5.15\n..."
}
```

### 4.3 生成ルール

1. `alarm_inputs` ごとに `mqtt in` → `switch` → `push notification` チェーン
2. `motion_inputs` は `rbe`（Report By Exception）でデバウンス
3. `outputs` は `mqtt out` + `ui_button`（Dashboard 連携オプション）
4. 全ノードに `z`（タブ ID）を案件 slug で固定命名

## 5. 新規モジュール

```
estimate_mode/node_red_flow_generator.py
```

| 関数 | 説明 |
|------|------|
| `build_flow_context(config_path, device_map_path)` | 入力 JSON/CSV 読込 |
| `generate_mqtt_broker_node(ctx)` | broker 設定ノード |
| `generate_alarm_flow_nodes(ctx)` | 警報フロー |
| `generate_motion_flow_nodes(ctx)` | 動体フロー |
| `generate_output_flow_nodes(ctx)` | 出力フロー |
| `generate_flows_json(ctx)` | flows.json 文字列 |
| `flows_json_valid(text)` | 監査用 |

## 6. CLI / パイプライン統合

```powershell
python project_generator.py --toms-site-report --estimate-file estimate_mode/estimate_sample.txt
# v5.15 以降: 上記実行時に TISLY/flows.json も自動生成
```

オプション（検討）:

```
--node-red-flow    # flows.json のみ再生成
```

`build_toms_site_report_project()` 内で `_write_tisly_folder()` の直後に  
`_write_node_red_flow_file()` を呼び出す。

## 7. 監査項目

| 項目 | 条件 |
|------|------|
