# MINPAKU_TEMPLATE — 民泊・ゲストハウス

> TiSLY PLC Builder v1 / Template Library v2  
> テンプレートID: `TPL-MINPAKU-001`

---

## 概要

民泊・ゲストハウス向け監視システム。  
**人数カウント**、**赤外線（PIR）**、**満室表示**、**清掃モード** を 001〜007 の部品で構成します。

---

## 機能要件

| 機能 | 説明 | 対応部品 |
|------|------|---------|
| 人数カウント | 入口センサーで入退室を検知し警報ラッチ | 005 |
| 赤外線（PIR） | 客室・共用部の人感検知 | 005 |
| 満室表示 | 定員到達時の看板ランプ点灯 | 007 |
| 清掃モード | 清掃中は PIR ラッチを無効化（001 で切替） | 001 |

---

## 使用部品番号一覧

| 順序 | 部品番号 | 部品名 | 本テンプレートでの役割 |
|------|---------|--------|----------------------|
| 1 | **001** | SELF HOLD | X0 チェックイン完了 → M0 監視モード |
| 2 | **001** | SELF HOLD | X4 清掃モード → M3 清掃中（監視一時停止） |
| 3 | **002** | ESTOP | X1 緊急停止 → 全 RST |
| 4 | **005** | SENSOR LATCH | M0 + X2 → M1 玄関ドア警報 |
| 5 | **005** | SENSOR LATCH | M0 + /M3 + X3 → M2 PIR 赤外線警報 |
| 6 | **005** | SENSOR LATCH | M0 + X5 → M4 人数超過警報 |
| 7 | **003** | BLINK SLOW | M0 + SM413 → Y0 監視中 LED 点滅 |
| 8 | **004** | BLINK FAST | M2 + SM412 → Y0 高速点滅（侵入警告） |
| 9 | **006** | RED LIGHT PRIORITY | M2 優先 / M0 低速 → M20 |
| 10 | **007** | OUTPUT CONTROL | 各警報・表示出力 |

**部品セット:** `001, 001, 002, 003, 004, 005, 005, 005, 006, 007`

## テンプレート構成図

```
┌─────────────────────────────────────────────────────────────────┐
│                   MINPAKU TEMPLATE                              │
└─────────────────────────────────────────────────────────────────┘

  [001] SELF HOLD — 監視モード
  X0（チェックイン完了）──→ SET M0
  /X0 ──→ RST M0/M1/M2/M4
        │
  [001] SELF HOLD — 清掃モード
  X4（清掃スイッチ）──→ SET M3
  /X4 ──→ RST M3
        │
        ▼
  [002] ESTOP
  X1 ──→ RST 全 M + 全 Y
        │
        ▼
  [005] SENSOR LATCH ×3
  M0 + X2 ──→ M1（玄関ドア）
  M0 + /M3 + X3 ──→ M2（PIR 赤外線 ※清掃中無効）
  M0 + X5 ──→ M4（人数超過）
        │
        ├──────────────────────────┐
        ▼                          ▼
  [003] BLINK SLOW            [004] BLINK FAST
  M0 + SM413 → 監視中          M2 + SM412 → 侵入警告
        │                          │
        └──────────┬───────────────┘
                   ▼
        [006] RED LIGHT PRIORITY → M20
                   │
                   ▼
        [007] OUTPUT CONTROL
        M20  → Y0  監視/警告 LED
        M4   → Y1  満室表示看板
        M1   → Y2  廊下灯
        M2   → Y3  サイレン
        M3   → Y4  清掃中表示灯
```

## I/O 割り当て

### 入力 (X)

| デバイス | 名称 | 部品 | 用途 |
|---------|------|------|------|
| X0 | チェックイン完了 SW | 001 | 監視モード開始 |
| X1 | 緊急停止ボタン | 002 | 全停止 |
| X2 | 玄関ドアセンサー | 005 | ドア開閉検知 → M1 |
| X3 | PIR 赤外線センサー | 005 | 人感検知 → M2 |
| X4 | 清掃モード SW | 001 | 清掃中フラグ → M3 |
| X5 | 人数カウントセンサー | 005 | 定員超過 → M4 |

### 出力 (Y)

| デバイス | 名称 | 部品 | 動作 |
|---------|------|------|------|
| Y0 | 監視/警告 LED | 003+004+006+007 | 監視中: 1s点滅 / 侵入: 高速点滅 |
| Y1 | 満室表示看板 | 007 | M4 ON → 常時点灯 |
| Y2 | 廊下灯 | 007 | M1 ON → 常時点灯 |
| Y3 | サイレン | 007 | M2 ON → 常時 ON |
| Y4 | 清掃中表示灯 | 007 | M3 ON → 常時点灯 |

### 内部リレー (M)

| デバイス | 名称 | 部品 |
|---------|------|------|
| M0 | 監視モード中 | 001 |
| M1 | 玄関ドア警報 | 005 |
| M2 | PIR 侵入警報 | 005 |
| M3 | 清掃モード中 | 001 |
| M4 | 人数超過警報 | 005 |
| M20 | Y0 制御 | 006, 007 |

---

## 清掃モード動作

```
清掃モード ON (X4 → M3)
    │
    ├─ PIR (X3) の 005 ラッチ条件に /M3 を追加
    │   → 清掃中は人感検知しても M2 ラッチしない
    │
    └─ Y4 清掃中表示灯 ON
```

---

## 状態遷移

```
チェックイン(X0) ──→ 監視中(M0) ──X3──→ PIR警報(M2)
                         │                    │
                    X2(ドア)──→ M1           │
                         │                    │
                    X5(人数)──→ M4(満室)      │
                         │                    │
清掃(X4)──→ M3 ──→ PIR無効                   │
                         │                    │
X0 OFF / X1 ESTOP ◄────────┴────────────────────┘
```
