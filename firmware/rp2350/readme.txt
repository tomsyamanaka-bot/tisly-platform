TiSLY RP2350 ガスメーター実機配備手順

対象機種:
Waveshare RP2350-POE-ETH-8DI-8RO

事前準備:
1. Waveshare配布のRP2350B用MicroPythonを本体へ書き込みます。
2. PoE対応LANケーブル、または7〜36V電源とLANを接続します。

Thonnyでコピーする手順:
1. USB Type-Cで本体とパソコンを接続します。
2. Thonnyのインタプリタで「MicroPython (Raspberry Pi Pico)」を選択します。
3. ZIP内のconfig.jsonとmain.pyを、本体ルート「/」へコピーします。
4. Thonnyの停止ボタンを押した後、本体を再起動します。

USB接続でコピーする手順:
1. MicroPythonのファイル転送ツールで本体ルート「/」を開きます。
2. config.jsonとmain.pyをコピーし、本体を再起動します。

配線:
DI1 = ガスメーターパルス入力（GPIO9、立下り、50msデバウンス）
DI2 = 地震遮断接点入力（GPIO10、接点変化を即時送信）
DI3〜DI8 = GPIO11〜GPIO16

オンボード機能:
W5500 = SPI0（SCK GPIO34、MOSI GPIO35、MISO GPIO36）
W5500 = CS GPIO33、RST GPIO25、INT GPIO32
RGB LED = WS2812 GPIO2（通信成功時に緑点滅）

通信:
・PoE/LAN接続後、DHCPでIPアドレスを自動取得します。
・DI1の未送信パルスは本体内のキューへ保存します。
・通信復旧後、未送信パルスをまとめて再送します。
・60秒ごとに同じ計測APIへ生存通信を送ります。

動作確認:
1. 起動ログに「Ethernet IP」が表示されることを確認します。
2. TiSLYの「現場ポートマッピング」で実機オンラインを確認します。
3. DI1を1回入力し、積算パルスが1増えることを確認します。
4. DI2を動作させ、緊急遮断表示へ切り替わることを確認します。
5. 正常送信時にオンボードRGB LEDが緑点滅することを確認します。

注意:
・config.jsonには機器認証情報が入っています。第三者へ渡さないでください。
・入出力配線や保守作業は、必ず電源を切って有資格者が行ってください。
・リレー負荷回路には、用途に合うヒューズや遮断器を設置してください。
