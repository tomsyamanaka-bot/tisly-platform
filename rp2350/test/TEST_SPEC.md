## T1 — DI1（赤外線①）反応確認

**目的**: 赤外線①検知で外灯① ON、MQTT、イベントが出ること。

**手順**

1. 配線: 赤外線① → DI1（COM/NO は受動接点仕様に従う）
2. `mosquitto_sub -t 'tisly/home/#' -v` を起動
3. 赤外線ビームを遮断（またはテストで DI1 をアクティブ）
4. RO1（外灯①）が ON になることを目視
5. `tisly/home/di/1` = `1`、`tisly/home/relay/1` = `1`
6. `tisly/home/event` に `ir_beam` 系 JSON

**合格**: 上記すべて満たす。OFF 時に外灯① OFF（仕様どおり）。

## T5 — 非常ボタン（DI7）確認

**手順**

1. 非常ボタン押下
2. RO1〜RO8 すべて ON
3. `tisly/home/alarm` → `"active":1`（retain）
4. Node-RED アラーム UI が赤表示
5. `tisly/home/cmd/alarm_clear` 送信で全 OFF・アラーム解除
