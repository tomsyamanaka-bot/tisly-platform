# TiSLY PLC Template Library v1

TiSLY_HOME_Security_DEMO を分解した **再利用可能な PLC 部品ライブラリ** です。  
三菱電機 FX 系 PLC（FX3U / FX5U）と GX Works2 / GX Works3 を想定しています。

---

## ライブラリ構成

```
PLC_TEMPLATE_LIBRARY/
├── README.md                    … 本ファイル
├── 001_SELF_HOLD.md             … 警戒ON保持（X0 → M0）
├── 002_ESTOP.md                 … 非常停止（X1 → 全RST）
├── 003_BLINK_SLOW.md            … 1秒点滅（SM413）
├── 004_BLINK_FAST.md            … 0.1秒点滅（SM412）
├── 005_SENSOR_LATCH.md          … センサー検知保持（M0 + X → SET）
├── 006_RED_LIGHT_PRIORITY.md    … 高速点滅優先（M2 > M0）
├── 007_OUTPUT_CONTROL.md        … Y出力制御（M20・二重コイル回避）
└── 008_HOME_SECURITY_DEMO.md    … 完成版構成図・部品組み合わせ
```

## 組み立て手順

新しい PLC プログラムを作るときは、以下の順序で部品を配置します。

```
1. 001_SELF_HOLD      … 運転/警戒モードの保持
2. 002_ESTOP          … 非常停止（必ず出力より前）
3. 005_SENSOR_LATCH   … センサー入力のラッチ（必要数だけ複製）
4. 003 + 004 + 006    … 点滅ロジック（出力が複数条件の場合）
5. 007_OUTPUT_CONTROL … Y 出力（1 Y = 1 OUT を厳守）
```

008_HOME_SECURITY_DEMO を **設計図** として参照し、I/O 割り当てと段構成を確認してください。

## デバイス命名規則

| 種別 | 範囲 | 用途 |
|------|------|------|
| X | X0〜Xn | 物理入力（スイッチ・センサー） |
| Y | Y0〜Yn | 物理出力（ランプ・リレー） |
| M0 | — | 001 保持リレー（armed / 稼働中） |
| M1〜M9 | — | 005 ラッチ群（警報保持） |
| M10〜M19 | — | 003/004 点滅中間（拡張用） |
| M20〜M29 | — | 007 出力集約（drive リレー） |
| SM412/SM413 | — | 004/003 クロック（FX3U: M8012/M8013） |

---

## 設計原則

1. **002_ESTOP を最優先** — すべての制御より前に配置
2. **1 Y = 1 OUT** — 二重コイル禁止。複数条件は M20 等で集約（007）
3. **SET/RST で状態管理** — OUT 自己保持より SET/RST を推奨（001, 005）
4. **点滅は SM412/SM413** — タイマー命令より内蔵クロックを使用（003, 004）
5. **優先度を明示** — 複数点滅条件は 006 で ORB + ANI 排他

---

## 優先度（Y0 赤ライト標準）

```
002_ESTOP  >  004 高速(M2)  >  003 低速(M0)  >  OFF
```

## FX3U / FX5U 互換表

| 機能 | FX5U (iQ-F) | FX3U |
|------|------------|------|
| 1秒クロック | SM413 | M8013 |
| 0.1秒クロック | SM412 | M8012 |
| SET/RST/ORB | 同一 | 同一 |

FX3U プロジェクトではテンプレート内の `SM413` → `M8013`、`SM412` → `M8012` に置換してください。
