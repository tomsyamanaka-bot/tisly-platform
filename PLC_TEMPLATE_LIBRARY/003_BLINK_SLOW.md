# 003 BLINK_SLOW — 低速点滅（1秒）

> TiSLY PLC Template Library v1  
> 部品ID: `TPL-003`  
> 由来: TiSLY_HOME_Security_DEMO 段6（低速側）・段8

---

## 概要

PLC 内蔵クロック **SM413（1秒）** を利用し、条件成立時に **1秒周期** で点滅させる部品です。  
警戒中の赤ライトや注意喚起ランプに使用します。

```
条件 + SM413 ──→ 1秒点滅
```

---

## クロックデバイス

| 機種 | デバイス | 周期 | 備考 |
|------|---------|------|------|
| FX5U / iQ-F | **SM413** | 1秒 (0.5s ON/OFF) | 本テンプレート標準 |
| FX3U 系 | M8013 | 1秒 (0.5s ON/OFF) | 互換エイリアス |

> SM413 / M8013 は PLC 起動時から自動で ON/OFF を繰り返します。  
> プログラムでの SET/RST は不要です。

---

## 用途

| シーン | 割り当て例 |
|--------|-----------|
| ホームセキュリティ | 警戒中 赤ライト低速点滅 |
| 工場 | 待機中 黄色ランプ点滅 |
| 民泊 | 監視中 LED 点滅 |
| 車屋 | 夜間警備中 表示灯 |
| 倉庫 | 在庫監視中 警告灯 |

---

## パラメータ（置換可能）

| 記号 | デフォルト | 説明 |
|------|-----------|------|
| `{M_COND}` | M0 | 点滅条件（警戒中等） |
| `{CLK_SLOW}` | SM413 | 1秒クロック（FX3U: M8013） |
| `{M_OUT}` | M20 | 出力先（内部リレー or 直接 Y） |

---

## ラダー図

### パターンA：条件 + クロック → 内部リレー

```
コメント: {M_COND} ON かつ 1秒CLK → {M_OUT}
|----[ {M_COND} ]----[ {CLK_SLOW} ]----( {M_OUT} )----|
```

### パターンB：006_RED_LIGHT_PRIORITY 内の低速側

```
コメント: 高速条件 OFF 時のみ低速有効
|----[/ {M_HIGH} ]----[ {M_COND} ]----[ {CLK_SLOW} ]----+
                                                          |
（006 と ORB で結合）                                      +----( {M_OUT} )----|
```

### パターンC：出力直接点滅（Y2 等）

```
コメント: 警報保持 + 1秒CLK → 出力点滅
|----[ {M_LATCH} ]----[ {CLK_SLOW} ]----( {Y_n} )----|
```

---

## 命令語（IL）

```il
; パターンA：単独低速点滅
LD     {M_COND}
AND    {CLK_SLOW}
OUT    {M_OUT}

; パターンC：出力直接点滅（HOME Security 段8）
LD     {M_LATCH}
AND    {CLK_SLOW}
OUT    {Y_n}
```

---

## 動作仕様

1. `{M_COND}` が ON かつ `{CLK_SLOW}` が ON のときのみ `{M_OUT}` / `{Y_n}` が ON
2. 周期: 約 **1秒**（0.5秒 ON → 0.5秒 OFF）
3. `{M_COND}` が OFF → 出力も OFF（クロック単独では出力しない）

---

## 設計メモ

- Y 出力を複数条件から駆動する場合は **007_OUTPUT_CONTROL** と組み合わせ、二重コイルを回避
- 006_RED_LIGHT_PRIORITY と併用時は ANI 条件で高速側との排他を取る
- FX3U プロジェクトでは `{CLK_SLOW}` を M8013 に置換

---

## 組み合わせ例

```
003_BLINK_SLOW（M0 + SM413 → M20 低速側）
      +
006_RED_LIGHT_PRIORITY（M2 + SM412 優先）
      ↓
007_OUTPUT_CONTROL（M20 → Y0）
```
