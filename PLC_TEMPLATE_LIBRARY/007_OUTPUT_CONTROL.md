# 007 OUTPUT_CONTROL — Y出力制御（二重コイル回避）

> TiSLY PLC Template Library v1  
> 部品ID: `TPL-007`  
> 由来: TiSLY_HOME_Security_DEMO 段6-2・段7〜10

---

## 概要

Y 出力を **単一コイル** で駆動し、二重コイル（同一 Y への複数 OUT）を回避する部品です。  
複数条件から駆動する出力は内部リレー **M20** で集約してから Y に接続します。

```
M20（集約） ──→ Y0（単一コイル）
M1 ──→ Y1
M1 + SM413 ──→ Y2
M2 ──→ Y3, Y4
```

---

## 二重コイル回避の原則

```
❌ NG:  Y0 を段A と 段B の両方から OUT
✅ OK:  段A/段B → M20 → 段C で Y0 を1回だけ OUT
```

---

## パラメータ（置換可能）

| 記号 | デフォルト | 説明 |
|------|-----------|------|
| `{M_DRIVE}` | M20 | Y0 集約内部リレー |
| `{Y_MAIN}` | Y0 | メイン出力（赤ライト等） |
| `{M_LATCH_1}` | M1 | 警報1 → 出力群 |
| `{M_LATCH_2}` | M2 | 警報2 → 出力群 |
| `{CLK_SLOW}` | SM413 | 点滅出力用（FX3U: M8013） |
| `{Y_*}` | Y1〜Y4 | 個別出力 |

---

## ラダー図

### Y0：M20 経由（単一コイル）

```
コメント: Y0 は M20 からのみ駆動
|----[ {M_DRIVE} ]----( {Y_MAIN} )----|
```

### Y1：常時点灯

```
コメント: 外周警報 → 常時点灯
|----[ {M_LATCH_1} ]----( {Y_1} )----|
```

### Y2：低速点滅

```
コメント: 外周警報 → 1秒点滅
|----[ {M_LATCH_1} ]----[ {CLK_SLOW} ]----( {Y_2} )----|
```

### Y3・Y4：常時点灯

```
コメント: 近接警報 → 常時点灯
|----[ {M_LATCH_2} ]----( {Y_3} )----|
|----[ {M_LATCH_2} ]----( {Y_4} )----|
```

---

## 命令語（IL）

```il
; Y0 — M20 経由（二重コイルなし）
LD     {M_DRIVE}
OUT    {Y_MAIN}

; Y1 — 常時点灯
LD     {M_LATCH_1}
OUT    {Y_1}

; Y2 — 1秒点滅
LD     {M_LATCH_1}
AND    {CLK_SLOW}
OUT    {Y_2}

; Y3 — 常時点灯
LD     {M_LATCH_2}
OUT    {Y_3}

; Y4 — 常時点灯
LD     {M_LATCH_2}
OUT    {Y_4}
```

---

## 出力マトリクス（HOME Security 標準）

| 状態 | Y0 | Y1 | Y2 | Y3 | Y4 |
|------|----|----|----|----|-----|
| 停止 | OFF | OFF | OFF | OFF | OFF |
| 警戒中 (M0) | 1s点滅 | OFF | OFF | OFF | OFF |
| 外周警報 (M1) | 1s点滅* | ON | 1s点滅 | OFF | OFF |
| 近接警報 (M2) | **0.1s点滅** | ※ | ※ | ON | ON |
| 非常停止 | OFF | OFF | OFF | OFF | OFF |

\* M2 ON 時は 006 により高速点滅が優先  
※ M1/M2 独立保持のため両方 ON 時は各条件が重なる

---

## 設計メモ

- `{Y_MAIN}` への OUT はプログラム内 **1箇所のみ**
- 002_ESTOP で `{Y_*}` を直接 RST（出力段より前の安全確保）
- 100V 負荷（Y1〜Y4）は **外部リレー必須**
- 出力点数: 本テンプレート標準 = 5点（Y0〜Y4）
