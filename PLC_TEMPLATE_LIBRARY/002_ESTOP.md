# 002 ESTOP — 非常停止

> TiSLY PLC Template Library v1  
> 部品ID: `TPL-002`  
> 由来: TiSLY_HOME_Security_DEMO 段3

---

## 概要

非常停止ボタン（X1）が ON になると、**全内部リレーと全出力を強制 RST** します。  
安全回路の最優先段として必ず配置します。

```
X1 ──→ 全RST（M0/M1/M2 + Y0〜Yn）
```

---

## 用途

| シーン | 割り当て例 |
|--------|-----------|
| ホームセキュリティ | 非常停止ボタン |
| 工場 | ライン非常停止 |
| 民泊 | 緊急停止スイッチ |
| 車屋 | シャッター非常停止 |
| 倉庫 | 搬送機非常停止 |

---

## パラメータ（置換可能）

| 記号 | デフォルト | 説明 |
|------|-----------|------|
| `{X_ESTOP}` | X1 | 非常停止入力（ON = 停止） |
| `{M_ARMED}` | M0 | 警戒中リレー |
| `{M_LATCH_*}` | M1, M2 | 警報ラッチ群 |
| `{Y_*}` | Y0〜Y4 | 全出力デバイス |

---

## ラダー図

```
コメント: 非常停止 ON → 全状態・全出力 RST
|----[ {X_ESTOP} ]----+----( RST {M_ARMED} )----|
                      +----( RST {M_LATCH_1} )----|
                      +----( RST {M_LATCH_2} )----|
                      +----( RST {Y_0} )----|
                      +----( RST {Y_1} )----|
                      +----( RST {Y_2} )----|
                      +----( RST {Y_3} )----|
                      +----( RST {Y_4} )----|
```

---

## 命令語（IL）

```il
; 非常停止 — 全RST
LD     {X_ESTOP}
RST    {M_ARMED}
RST    {M_LATCH_1}
RST    {M_LATCH_2}
RST    {Y_0}
RST    {Y_1}
RST    {Y_2}
RST    {Y_3}
RST    {Y_4}
```

---

## 動作仕様

1. `{X_ESTOP}` が ON → 即座に全 M / 全 Y を RST
2. 001_SELF_HOLD の SET より **優先**（001 段の ANI 条件でもブロック）
3. 出力段より **前** に配置し、Y への直接 RST を行う

---

## 優先度

```
{X_ESTOP}  >  すべての制御ロジック  >  OFF
```

---

## 設計メモ

- 配線は **b接点（NC）** 推奨 → 断線時も安全側
- 本プログラムは `{X_ESTOP}` = ON で停止。NC 配線の場合は入力反転または X 論理を調整
- **ハードウェア安全回路**（リレーインターロック等）と必ず併用
- 001_SELF_HOLD の直後、005_SENSOR_LATCH の前に配置

---

## 組み合わせ例
