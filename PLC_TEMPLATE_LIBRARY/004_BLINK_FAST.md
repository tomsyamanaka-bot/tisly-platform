# 004 BLINK_FAST — 高速点滅（0.1秒）

> TiSLY PLC Template Library v1  
> 部品ID: `TPL-004`  
> 由来: TiSLY_HOME_Security_DEMO 段6（高速側）

---

## 概要

PLC 内蔵クロック **SM412（0.1秒）** を利用し、条件成立時に **0.1秒周期** で高速点滅させる部品です。  
侵入・重大警報など、最も危険な状態の強調表示に使用します。

```
条件 + SM412 ──→ 0.1秒点滅（高速）
```

---

## クロックデバイス

| 機種 | デバイス | 周期 | 備考 |
|------|---------|------|------|
| FX5U / iQ-F | **SM412** | 0.1秒 (0.05s ON/OFF) | 本テンプレート標準 |
| FX3U 系 | M8012 | 0.1秒 (0.05s ON/OFF) | 互換エイリアス |

> SM412 / M8012 は PLC 起動時から自動で ON/OFF を繰り返します。  
> プログラムでの SET/RST は不要です。

---

## 用途

| シーン | 割り当て例 |
|--------|-----------|
| ホームセキュリティ | 近接侵入 赤ライト高速点滅 |
| 工場 | 異常停止 赤ランプ高速点滅 |
| 民泊 | 不正侵入 警告灯 |
| 車屋 | 盗難検知 サイレン連動灯 |
| 倉庫 | 火災・ガス検知 警報灯 |

---

## パラメータ（置換可能）

| 記号 | デフォルト | 説明 |
|------|-----------|------|
| `{M_ALARM}` | M2 | 高速点滅条件（近接警報等） |
| `{CLK_FAST}` | SM412 | 0.1秒クロック（FX3U: M8012） |
| `{M_OUT}` | M20 | 出力先（内部リレー） |

---

## ラダー図

### パターンA：単独高速点滅

```
コメント: {M_ALARM} ON かつ 0.1秒CLK → {M_OUT}
|----[ {M_ALARM} ]----[ {CLK_FAST} ]----( {M_OUT} )----|
```

### パターンB：006_RED_LIGHT_PRIORITY 内の高速側（優先）

```
コメント: {M_ALARM} 成立時 高速点滅（最優先）
|----[ {M_ALARM} ]----[ {CLK_FAST} ]----+
                                         |
（003 低速側と ORB で結合）               +----( {M_OUT} )----|
```

---

## 命令語（IL）

```il
; パターンA：単独高速点滅
LD     {M_ALARM}
AND    {CLK_FAST}
OUT    {M_OUT}

; パターンB：006 優先結合（高速側）
LD     {M_ALARM}
AND    {CLK_FAST}
LD     {M_ARMED}
ANI    {M_ALARM}
AND    {CLK_SLOW}
ORB
OUT    {M_OUT}
```

---

## 動作仕様

1. `{M_ALARM}` が ON かつ `{CLK_FAST}` が ON のとき `{M_OUT}` が ON
2. 周期: 約 **0.1秒**（0.05秒 ON → 0.05秒 OFF）
3. 003_BLINK_SLOW より **優先**（006_RED_LIGHT_PRIORITY で制御）

---

## 設計メモ

- 003 低速点滅と同一 Y 出力を共有する場合は必ず **006** を経由
- 単独出力（Y3, Y4 等）への常時点灯は 004 不要 → 007 で直接 OUT
- FX3U プロジェクトでは `{CLK_FAST}` を M8012 に置換

---

## 組み合わせ例

```
005_SENSOR_LATCH（X3 → M2 SET）
      ↓
004_BLINK_FAST（M2 + SM412）
      ↓
006_RED_LIGHT_PRIORITY（M2 優先 / M0 低速）
      ↓
007_OUTPUT_CONTROL（M20 → Y0）
```
