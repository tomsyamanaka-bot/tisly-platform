iPhone セットアップ手順

Safari↓ ホーム画面追加↓ Push 登録↓ Push テスト
  1. Safari でこのページ（/remote-test）を開く
  2. 共有ボタン → ホーム画面に追加
  3. ホーム画面の TiSLY Remote から起動
  4. Push 登録 → 通知を許可
  5. Push テスト で通知を確認

iOS 16.4 以降、ホーム画面 PWA のみ Web Push に対応します。
