保存方式

スマホからは常に VPS プロキシ経由で QNAP へ保存します（CORS / Mixed Content 回避）。VPS が Tailscale または LAN 経由で nastoms に到達できる必要があります。

QNAP設定（ローカルLAN）

書類保存用NAS (nastoms): 192.168.1.134 — 見積書・請求書PDFの保存先

システム用NAS (TiSLYNAS): 192.168.1.10 — 将来のTiSLYシステムデータ・ログ保管用

見積書・請求書の保存先（nastoms）。未入力時は自動で 192.168.1.134 へ接続します。システム用 TiSLYNAS（192.168.1.10）とは別です。

WebDAV Basic 認証に使用します。既定ユーザーは tomsadmin。未入力時は VPS の QNAP_USER / QNAP_PASSWORD（または QNAP_WEBDAV_*）を参照します。例: 192.168.1.134 / 5005 / TiSLY

接続テスト（Ping）

1タップで設定保存 → Ping診断まで実行します。応答速度（ms）またはエラーをすぐ表示します。
