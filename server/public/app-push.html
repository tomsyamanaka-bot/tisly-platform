iPhone で Push 登録する手順

  1. Safari で tisly.jp/app/push を開く（Chrome アプリ内ブラウザは不可）
  2. 共有ボタン → ホーム画面に追加
  3. ホーム画面の TiSLY アイコンから起動（スタンドアロン表示を確認）
  4. この画面で Push 登録 → 通知を許可

iOS 16.4 以降、ホーム画面 PWA のみ Web Push に対応します。通常 Safari タブからは登録できません。
