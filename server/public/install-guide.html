施工 PWA をインストール

App Store / Google Play 不要 — URL からホーム画面に追加して使います（施工員専用）。

iPhone（Safari）

  1. Safari で施工 URL を開く
  2. 共有 □↑ → ホーム画面に追加
  3. 名前「TiSLY施工」で追加
  4. ホーム画面のアイコンから起動（フルスクリーン）

詳細: docs/ios_pwa_install_guide.md

Android（Chrome）

  1. Chrome で施工 URL を開く
  2. メニュー → アプリをインストール または下部のプロンプト
  3. QR スキャン時はカメラ権限を許可

すでにスタンドアロンで起動しています。

詳細: docs/android_pwa_install_guide.md
