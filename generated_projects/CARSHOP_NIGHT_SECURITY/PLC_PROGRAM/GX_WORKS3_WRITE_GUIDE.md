# GX Works3 書き込み手順 — CARSHOP_NIGHT_SECURITY デモPLC

対象PLC: FX5UJ-24MR/ES  
貼り付けファイル: `GX_WORKS3_PASTE_FINAL.txt`

---

## 1. GX Works3 新規プロジェクト作成

1. GX Works3 を起動する。
2. メニュー **[プロジェクト]** → **[新規作成]** を選ぶ。
3. プロジェクト名（例: CARSHOP_NIGHT_SECURITY_DEMO）と保存先を指定し **[OK]** をクリックする。

## 2. FX5UJ-24MR/ES 選択

1. **PLC シリーズ** で **FXCPU** を選ぶ。
2. **PLC タイプ** で **FX5UJ-24MR/ES** を選ぶ。
3. プログラム言語は **ラダー (LAD)** のまま **[OK]** で確定する。

> SM412 / SM413 を使用するため、FX5U 系以外は選ばないこと。

## 3. MAIN を開く

1. プロジェクトツリーで **プログラム** → **MAIN** をダブルクリックする。
2. ツールバーが **書込モード**（鉛筆アイコン）であることを確認する。

## 4. 命令リスト入力へ貼り付け

1. MAIN エディタで右クリック → **[表示形式]** → **[命令入力]** を選ぶ。
2. 既存命令があれば全選択して削除する。
3. `GX_WORKS3_PASTE_FINAL.txt` を開き、**Ctrl+A** → **Ctrl+C** で全文コピーする。
4. 命令入力ビューの先頭行で **Ctrl+V** で貼り付ける。
5. 先頭が `LD X0`、末尾が `END` であることを確認する。

## 5. 変換

1. 命令入力ビュー内の任意の行を選択する。
2. **[命令入力→ラダー変換]** をクリックする（ショートカット **F4**）。

## 6. エラー確認

1. メニュー **[変換]** → **[プログラムチェック]** を実行する。
2. エラー 0 件であることを確認する。
3. Y0 二重コイル警告が出ないこと（OUT Y0 は M20 経由 1 か所のみ）。
4. SM412 / SM413 が未定義エラーにならないことを確認する。

## 7. PLC 接続

1. PLC を PC に接続する（USB または Ethernet）。
2. メニュー **[オンライン]** → **[接続先の指定]** で通信設定を行う。
3. **[オンライン]** → **[接続]** で PLC に接続する。

## 8. 書き込み

1. メニュー **[オンライン]** → **[書込]** を選ぶ。
2. **プログラム** にチェックを入れ **[実行]** をクリックする。
3. 書込み完了を確認する。

## 9. RUN

1. メニュー **[オンライン]** → **[リモート RUN]** を選ぶ。
2. PLC が RUN 状態であることを確認する。

## 10. X0 / X2 / X3 / X1 で動作確認

PLC が RUN の状態で、以下の順に入力を操作する。

### X0 ON（夜間警戒）

| 確認 | 期待 |
|------|------|
| M0 | ON |
| Y0 | 低速点滅（SM413、約 1 秒周期） |

### X2 ON（外周センサー）※ X0 は ON のまま

| 確認 | 期待 |
|------|------|
| M1 | ON |
| Y1 | 点灯 |
| Y2 | 低速点滅 |

### X3 ON（近接センサー）※ X0 は ON のまま

| 確認 | 期待 |
|------|------|
| M2 | ON |
| Y3 | 点灯 |
| Y4 | 点灯 |
| Y0 | 高速点滅（SM412、M2 優先） |

### X1 ON（非常停止）

| 確認 | 期待 |
|------|------|
| M0 / M1 / M2 | OFF |
| Y0 ～ Y4 | 全消灯 |
