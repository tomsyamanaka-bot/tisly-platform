TiSLY_HOME_Security_DEMO — GX Works 作業メモ
=============================================

【プロジェクト設定】
  プロジェクト名 : TiSLY_HOME_Security_DEMO
  PLC機種         : FX3U-32MT 等（入出力点数に応じて選択）
  プログラム言語   : ラダー

【ラダーコメント一覧（各段に設定）】
  段1  : 警戒ON保持 — セレクタONかつ非常停止でない→M0 SET
  段2  : 警戒OFFリセット — X0 OFF→M0/M1/M2 RST
  段3  : 非常停止 — X1 ON→全リセット・全出力OFF
  段4  : センサー1警報保持 — 外周検知 M0+X2→M1 SET
  段5  : センサー2警報保持 — 近接検知 M0+X3→M2 SET
  段6  : Y0赤ライト制御 — M20合成（M2高速優先）
  段7  : Y1白ライト1 — 外周警報 常時点灯
  段8  : Y2白ライト2 — 外周警報 1秒点滅
  段9  : Y3白ライト3 — 近接警報 常時点灯
  段10 : Y4白ライト4 — 近接警報 常時点灯

【デバイスコメント（推奨）】
  X0  : セレクタ/警戒ON
  X1  : 非常停止
  X2  : ビーム1/外周
  X3  : ビーム2/近接
  Y0  : 24V赤ライト
  Y1  : 100V白1
  Y2  : 100V白2
  Y3  : 100V白3
  Y4  : 100V白4
  M0  : 警戒中
  M1  : 外周警報保持
  M2  : 近接警報保持
  M20 : Y0制御

【動作確認チェックリスト】
  □ X0 ON  → Y0 が約1秒周期で点滅
  □ X0 OFF → 全出力 OFF、M1/M2 も解除
  □ 警戒中 X2 ON → Y1 点灯、Y2 点滅、M1 保持
  □ 警戒中 X3 ON → Y3/Y4 点灯、Y0 高速点滅
  □ M2 ON 時 Y0 は M0 単独より速い点滅
  □ X1 ON  → 即全停止

【注意】
  - M8012/M8013 は RUN 中のみ動作（PLC 内蔵クロック）
  - 非常停止実機が NC 接点の場合は段1・段3の X1 論理を反転すること
