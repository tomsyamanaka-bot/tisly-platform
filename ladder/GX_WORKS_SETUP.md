# GX Works セットアップ手順

## 1. プロジェクト作成

1. GX Works2 / GX Works3 を起動
2. **新規作成** → PLC シリーズ：**FXCPU**（FX3U 等）または **FX5U**
3. プロジェクト名：**TiSLY_HOME_Security_DEMO**
4. プログラム言語：**ラダー** または **指令語**

## 2. プログラム取り込み

### 方法A：ラダー手入力（推奨）

`LADDER_DIAGRAM.md` の段1〜段10を順に入力してください。

### 方法B：指令語リスト

1. プログラム編集画面で **指令語** 表示に切替
2. `TiSLY_HOME_Security_DEMO.il` の内容を MAIN に貼り付け
3. **ラダー** 表示に戻して回路を確認

## 3. デバイスコメント

`DEVICE_COMMENTS.csv` を GX Works のデバイスコメント一括登録機能で取り込むか、  
各デバイスに手動でコメントを設定してください。

## 4. 各段コメント（ラダー段コメント欄）

| 段 | 段コメント |
|----|-----------|
| 1 | 警戒ON保持 |
| 2 | 警戒OFFリセット |
| 3 | 非常停止 |
| 4 | センサー1警報保持 |
| 5 | センサー2警報保持 |
| 6 | Y0赤ライト制御(M20) |
| 7 | Y1白ライト1 |
| 8 | Y2白ライト2 |
| 9 | Y3白ライト3 |
| 10 | Y4白ライト4 |

## 5. コンパイル・書込

1. **コンパイル** → エラー 0 を確認
2. PLC に **書込**
3. **RUN** に切替えて動作確認

## 6. シミュレーション

GX Works2 シミュレータ / FX5 シミュレータで以下を確認：

- X0 ON → Y0 が 1 秒周期で点滅
- X0 ON + X2 ON → Y1 点灯、Y2 点滅
- X0 ON + X3 ON → Y3/Y4 点灯、Y0 高速点滅（低速より優先）
- X0 OFF または X1 ON → 全出力 OFF、警報解除
