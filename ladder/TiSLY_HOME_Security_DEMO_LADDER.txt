 三菱 FX 系 / GX Works2・3 入力用参考図
==============================================================================

【記号】
  [ ]  : a接点 (NO)      [/]  : b接点 (NC)
  ( )  : コイル           (S)  : SET    (R)  : RST

==============================================================================
 段1 : 警戒 ON 保持
 セレクタ ON かつ非常停止でない → M0 SET
==============================================================================
  |---[ X0 ]---[/ X1 ]------------------------(S M0 )---|

==============================================================================
 段2 : 警戒 OFF リセット
 セレクタ OFF → M0 / M1 / M2 RST
==============================================================================
  |---[/ X0 ]----------------------------------(R M0 )---|
  |                                          (R M1 )---|
  |                                          (R M2 )---|

  ※ GX Works 上は 1 ステップに複数 RST を配置、または個別 RUNG で記述

==============================================================================
 段3 : 非常停止
 X1 ON → M0～M2 RST、Y0～Y4 OFF
==============================================================================
  |---[ X1 ]----------------------------------(R M0 )---|
  |                                          (R M1 )---|
  |                                          (R M2 )---|
  |                                          (R Y0 )---|
  |                                          (R Y1 )---|
  |                                          (R Y2 )---|
  |                                          (R Y3 )---|
  |                                          (R Y4 )---|

  ※ IL では ZRST M0 M2 / ZRST Y0 Y4 を使用

==============================================================================

 M0 かつ X2 → M1 SET
==============================================================================
  |---[ M0 ]---[ X2 ]---------------------------(S M1 )---|

==============================================================================
 段5 : センサー2 警報保持
 M0 かつ X3 → M2 SET

  |---[ M0 ]---[ X3 ]---------------------------(S M2 )---|

==============================================================================
 段6 : Y0 赤ライト制御 (M20 経由・単一 RUNG)
 M2=ON → M8012 高速点滅 / M2=OFF かつ M0=ON → M8013 低速点滅
==============================================================================
  |---[ M2 ]---[ M8012 ]---+
  |                        |
  |---[ M0 ]---[/ M2 ]---[ M8013 ]---+
  |                                  |
  +----------------------------------( M20 )---|

==============================================================================

 M20 → Y0 (二重コイルなし)
==============================================================================
  |---[ M20 ]-----------------------------------( Y0 )---|

==============================================================================
  |---[ M1 ]------------------------------------( Y1 )---|

==============================================================================
 段8 : Y2 白ライト2
 M1 ON かつ M8013 → Y2 点滅
==============================================================================
  |---[ M1 ]---[ M8013 ]------------------------( Y2 )---|

==============================================================================
 段9 : Y3 白ライト3
 M2 ON → Y3 常時点灯

==============================================================================
 段10 : Y4 白ライト4
 M2 ON → Y4 常時点灯
==============================================================================
  |---[ M2 ]------------------------------------( Y4 )---|

==============================================================================
 動作優先度 (Y0)
==============================================================================
  1. 非常停止 (X1)     → 全出力 OFF (最優先)
  2. 近接警報 (M2)     → Y0 高速点滅 (0.1s)
  3. 警戒中 (M0)       → Y0 低速点滅 (1s)
  4. 上記以外          → Y0 OFF

==============================================================================
 デバイス使用一覧
==============================================================================
  入力   : X0, X1, X2, X3
  出力   : Y0, Y1, Y2, Y3, Y4
  内部   : M0, M1, M2, M10*, M11*, M20
  クロック: M8012, M8013

  * M10, M11 は TiSLY 標準テンプレート拡張用に予約 (本 DEMO では未使用)
