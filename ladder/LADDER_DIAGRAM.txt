【記号】
  [ ]  a接点    [/]  b接点    ( )  コイル    [S] SET    [R] RST

------------------------------------------------------------------------------
 段1：警戒ON保持
  X0=ON かつ 非常停止でない → M0 SET
------------------------------------------------------------------------------
 |  セレクタ/警戒ON          非常停止未作動
 |----[ X0 ]----------------[/ X1 ]----[S M0 警戒中]----|

------------------------------------------------------------------------------
 段2：警戒OFFリセット
  X0=OFF → M0 / M1 / M2 RST
------------------------------------------------------------------------------
 |  警戒OFF
 |----[/ X0 ]----[R M0]----|
 |              ----[R M1]----|
 |              ----[R M2]----|

------------------------------------------------------------------------------
 段3：非常停止
  X1=ON → M0/M1/M2 RST、Y0〜Y4 OFF
------------------------------------------------------------------------------
 |  非常停止
 |----[ X1 ]----[R M0]----|
 |            ----[R M1]----|
 |            ----[R M2]----|
 |            ----[R Y0]----|
 |            ----[R Y1]----|
 |            ----[R Y2]----|
 |            ----[R Y3]----|
 |            ----[R Y4]----|

------------------------------------------------------------------------------
 段4：センサー1警報保持 (外周検知)
  M0 かつ X2 → M1 SET
------------------------------------------------------------------------------
 |  警戒中              外周検知
 |----[ M0 ]------------[ X2 ]----[S M1 センサー1警報]----|

------------------------------------------------------------------------------
 段5：センサー2警報保持 (近接検知)
  M0 かつ X3 → M2 SET
------------------------------------------------------------------------------
 |  警戒中              近接検知
 |----[ M0 ]------------[ X3 ]----[S M2 センサー2警報]----|

------------------------------------------------------------------------------
 段6：Y0 赤ライト制御 (M20 経由・Y0 二重コイルなし)
  M2 → M8012 高速点滅 / M0 → M8013 低速点滅 (M2 優先)
------------------------------------------------------------------------------
 |  近接警報              0.1s CLK
 |----[ M2 ]--------------[ M8012 ]----+
 |                                    |
 |  M2 OFF   警戒中        1s CLK     |
 |----[/ M2 ]--[ M0 ]----[ M8013 ]---+----[/ X1 ]----( M20 )----|
 |                                              |
 |                                              +----( Y0 赤24V )----|

  ※ M2=ON のとき M8012 点滅が M0 低速点滅より優先

------------------------------------------------------------------------------
 段7：Y1 白ライト1 — M1 ON で常時点灯
------------------------------------------------------------------------------
 |  外周警報            非常停止未作動
 |----[ M1 ]------------[/ X1 ]----( Y1 白100V-1 )----|

------------------------------------------------------------------------------
 段8：Y2 白ライト2 — M1 + 1秒CLK で点滅
------------------------------------------------------------------------------
 |  外周警報    1s CLK    非常停止未作動
 |----[ M1 ]----[ M8013 ]--[/ X1 ]----( Y2 白100V-2 )----|

------------------------------------------------------------------------------
 段9：Y3 白ライト3 — M2 ON で常時点灯
------------------------------------------------------------------------------
 |  近接警報            非常停止未作動
 |----[ M2 ]------------[/ X1 ]----( Y3 白100V-3 )----|

------------------------------------------------------------------------------
 段10：Y4 白ライト4 — M2 ON で常時点灯
------------------------------------------------------------------------------
 |  近接警報            非常停止未作動
 |----[ M2 ]------------[/ X1 ]----( Y4 白100V-4 )----|

==============================================================================
 動作イメージ (出力)
==============================================================================
 状態              | Y0 赤      | Y1   | Y2   | Y3   | Y4
 ------------------+------------+------+------+------+------
 警戒中 (M0)       | 1s点滅     | OFF  | OFF  | OFF  | OFF
 外周検知 (M1)     | 1s点滅*    | ON   | 1s点滅| OFF  | OFF
 近接検知 (M2)     | 0.1s高速** | OFF  | OFF  | ON   | ON
 非常停止 (X1)     | OFF        | OFF  | OFF  | OFF  | OFF

 * M0 警戒中のとき Y0 は低速点滅。M1 のみの場合も M0 が ON なので同様。
 ** M2 作動時は Y0 高速点滅が最優先 (M0 低速より優先)
