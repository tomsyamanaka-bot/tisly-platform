================================================================================
 GX Works2 / GX Works3 への取り込み手順
 プロジェクト名: TiSLY_HOME_Security_DEMO
================================================================================

1. 新規プロジェクト作成
   - シリーズ: FXCPU（お使いの機種に合わせる。例: FX3G, FX3U）
   - プログラム言語: ラダー
   - プロジェクト名: TiSLY_HOME_Security_DEMO

2. デバイスコメント登録
   - メニュー [表示] → [デバイスコメント] またはシンボル一覧
   - TiSLY_HOME_Security_DEMO_LADDER.txt の「デバイス一覧」を参照して登録

3. プログラム入力
   方法A（推奨）: TiSLY_HOME_Security_DEMO_LADDER.txt を見ながらラダー手入力
   方法B: 命令語モードで TiSLY_HOME_Security_DEMO.mnm を参照して入力
   ※実行順は mnm ファイルと同じ（非常停止→OFF→ON→警報→出力）

4. クロック確認
   - M8012, M8013 は FXの特殊補助リレー（RUN中自動ON/OFF）
   - 実機で点滅しない場合は PLC が RUN モードか確認

5. 監視デバイス（デモ時）
   - M0, M1, M2, M20, Y0〜Y4, X0〜X3

6. 強制出力
   - デモ配線確認時のみ。本番運用では強制を解除すること
