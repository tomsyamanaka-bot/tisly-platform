# TiSLY_HOME_Security_DEMO — ラダー図（参照用）

GX Works への転記・レビュー用 ASCII ラダー図です。

---

## 段1：警戒ON保持

```
コメント: セレクタ ON かつ非常停止でない → M0 SET
|----[ X0  セレクタ/警戒ON ]----[/ X1  非常停止 ]----( SET M0 警戒中 )----|
```

---

## 段2：警戒OFFリセット

```
コメント: セレクタ OFF → M0/M1/M2 すべて RST
|----[/ X0  セレクタ/警戒ON ]----+----( RST M0 )----|
                                 +----( RST M1 )----|
                                 +----( RST M2 )----|
```

---

## 段3：非常停止

```
コメント: 非常停止 ON → 全状態・全出力 RST
|----[ X1  非常停止 ]----+----( RST M0 )----|
                          +----( RST M1 )----|
                          +----( RST M2 )----|
                          +----( RST Y0 )----|
                          +----( RST Y1 )----|
                          +----( RST Y2 )----|
                          +----( RST Y3 )----|
                          +----( RST Y4 )----|
```

---

## 段4：センサー1警報保持

```
コメント: 警戒中 + 外周検知 → M1 SET
|----[ M0  警戒中 ]----[ X2  外周検知 ]----( SET M1 )----|
```

---

## 段5：センサー2警報保持

```
コメント: 警戒中 + 近接検知 → M2 SET
|----[ M0  警戒中 ]----[ X3  近接検知 ]----( SET M2 )----|
```

---

## 段6：Y0 赤ライト制御（M20 単一コイル）

```
コメント: M2 時 0.1s 高速点滅優先 / M0 時 1s 低速点滅
|----[ M2 ]----[ M8012  0.1sCLK ]----+----( M20  Y0制御 )----|
|----[/ M2 ]----[ M0 ]----[ M8013  1sCLK ]----+
```

## 段6-2：Y0 出力

```
コメント: Y0 は M20 からのみ駆動（二重コイルなし）
|----[ M20 ]----( Y0  24V赤ライト )----|
```

---

## 段7：Y1 白ライト1

```
コメント: 外周警報 M1 → 常時点灯
|----[ M1 ]----( Y1  白ライト1 )----|
```

---

## 段8：Y2 白ライト2

```
コメント: 外周警報 M1 → 1s 点滅
|----[ M1 ]----[ M8013 ]----( Y2  白ライト2 )----|
```

---

## 段9：Y3 白ライト3

```
コメント: 近接警報 M2 → 常時点灯
|----[ M2 ]----( Y3  白ライト3 )----|
```

---

## 段10：Y4 白ライト4

```
コメント: 近接警報 M2 → 常時点灯
|----[ M2 ]----( Y4  白ライト4 )----|
```

---

## 動作優先度（Y0）

| 条件 | Y0 動作 |
|------|---------|
| M2 ON（近接警報） | M8012 による **高速点滅**（最優先） |
| M0 ON かつ M2 OFF | M8013 による **低速点滅** |
| M0 OFF かつ M2 OFF | OFF |
| X1 非常停止 ON | 段3で Y0 直接 RST → OFF |
