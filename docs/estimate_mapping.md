# Notion → Excel データマッピング

> **TOMS Phase 2-1** — 現調DB → TOMS標準見積フォーマット.xlsx  
> 最終更新: 2026-05-31

---

## 1. 概要

本ドキュメントは、Notion 現調DB・案件管理DB の各プロパティが、  
`templates/TOMS標準見積フォーマット.xlsx` のどのセルに転記されるかを定義する。

---

## 2. ヘッダー部マッピング

| Excelセル | 項目名 | Notionソース | 備考 |
|-----------|--------|-------------|------|
| A1 | 会社名 | 環境変数 `TOMS_COMPANY_NAME` | 固定値（TiSLY株式会社） |
| G1 | 発行日 | 見積DB → 作成日 / 実行日 | `YYYY-MM-DD` 形式 |
| G2 | 見積番号 | 見積DB → 見積番号 | 未設定時は `EST-{YYYYMMDD}-{案件番号}` |
| C6 | 宛名 | 案件管理DB → 顧客名（Rollup） | `{顧客名} 御中` |
| A7 | 担当 | 案件管理DB → 担当者 | `担当: {名前}` |
| D9 | 件名 | 案件管理DB → 案件名 | 例: 土浦寮 |
| D17 | 税込合計（ヘッダー） | 計算値 | `¥{税込合計}` 形式 |

---

## 3. 明細行マッピング

| Excel列 | 項目名 | Notionソース（現調DB） | 変換ルール |
|---------|--------|----------------------|-----------|
| A（No） | 連番 | — | 1 から自動採番 |
| B（項目） | 工事項目名 | 場所 + 工事分類 + 作業内容 + 型式 | `{場所} {工事分類} {作業内容} ({型式})` |
| C（数量） | 数量 | 数量 | 整数 |
| D（単価） | 見積単価 | 見積単価（Formula） | 税抜・整数 |
| E（金額） | 見積金額 | 見積金額（Formula） | `見積単価 × 数量` |

### 明細行の開始位置

| 項目 | 値 |
|------|-----|
| ヘッダー行 | 11行目 |
| データ開始行 | 12行目 |
| 最大行数 | テンプレート依存（標準: 35行） |

### フィルター条件

| 条件 | 値 |
|------|-----|
| 見積反映 | `ON`（Checkbox = true）のみ転記 |
| 案件関連 | 指定案件番号に紐づく現調DBレコード |

---

## 4. 合計部マッピング

| Excelセル | 項目名 | Notionソース / 計算 |
|-----------|--------|-------------------|
| F47 | ラベル | 固定: `小計` |
| G47 | 小計 | 見積DB → 小計 / 明細合計 |
| F48 | ラベル | 固定: `消費税` |
| G48 | 消費税 | 見積DB → 消費税 / `小計 × 10%` |
| F49 | ラベル | 固定: `税込合計` |
| G49 | 税込合計 | 見積DB → 税込合計 / `小計 + 消費税` |

---

## 5. 備考部マッピング

| Excelセル | 項目名 | Notionソース |
|-----------|--------|-------------|
| A51 | 見出し | 固定: `〈備考〉` |
| A52〜 | 備考本文 | 案件管理DB → 備考 / 固定テンプレート |

## 6. 出力パスマッピング

| 要素 | Notionソース | 出力例 |
|------|-------------|--------|
| 顧客フォルダ | 顧客名（短縮） | `伝元` |
| 案件フォルダ | 案件名 | `土浦寮` |
| 年月フォルダ | 発行日 | `2026-05` |
| ファイル名 | 固定 | `見積書.xlsx` / `見積書.pdf` |

**出力パス例:**

```
output/伝元/土浦寮/2026-05/見積書.xlsx
output/伝元/土浦寮/2026-05/見積書.pdf
```

## 7. Notion プロパティ型対応表

| Notion型 | 読取方法 | 使用プロパティ |
|---------|---------|--------------|
| Title | plain_text 結合 | 案件名, 項目名, 顧客名 |
| Unique ID | prefix + number | 案件番号 |
| Relation | 関連ページ ID | 案件, 顧客名 |
| Rollup | array / number | 顧客名, 案件番号, 標準単価 |
| Select | name | 場所, 工事分類, 作業内容, 担当者 |
| Number | number | 数量 |
| Formula | string / number | 見積単価, 見積金額 |
| Checkbox | checkbox | 見積反映 |
| Text | plain_text | 型式・サイズ, 備考, 住所 |
| Date | start | 作成日, 現調日 |
