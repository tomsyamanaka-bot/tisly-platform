# 営業ダッシュボード — 設計・構築手順

> **TOMS Phase 1.5** — 今月の見積・受注・売上を一画面で把握  
> 最終更新: 2026-05-31

---

## 1. 目的

管理者（智紀さん）が毎朝開き、営業状況を **30 秒以内** で把握できるダッシュボード。

### 1.1 表示項目

| 指標 | 説明 | データソース |
|------|------|-------------|
| 今月見積件数 | 今月作成・提出した見積の件数 | 見積DB |
| 今月受注件数 | 今月受注確定した案件数 | 案件管理DB / 見積ライブラリDB |
| 今月売上 | 今月請求（または入金）の税込合計 | 請求DB |
| 未請求件数 | 施工完了だが未請求の案件 | 案件管理DB |
| 未入金件数 | 請求済み・入金未確認 | 請求DB |
| 現調待ち件数 | 現調前の案件 | 案件管理DB |

## 3. KPI の算出方法

Notion 単体ではダッシュボード用の「数値カード」ウィジェットが限定的なため、**Linked database + フィルター + 件数表示** で実現する。

| KPI | 実装方法 |
|-----|---------|
| 今月見積件数 | 見積DB Linked view → Filter: 作成日 is this month → 件数をヘッダーに手動記載 or ビュー名に `(12件)` |
| 今月受注件数 | 案件管理DB → Filter: 状態=受注 AND 状態変更日 or 作成日 this month |
| 今月売上 | 請求DB → Filter: 請求日 this month → 税込金額列の Sum（テーブル下部） |
| 未請求件数 | 案件管理DB → Filter: 状態=施工完了 |
| 未入金件数 | 請求DB → Filter: 入金確認=OFF |
| 現調待ち件数 | 案件管理DB → Filter: 状態=現調前 |

> Phase 2 以降、Notion API + 外部ダッシュボード（または Notion Charts）で数値カード自動更新を検討。

## 4. Notion 構築手順（初心者向け・詳細）

### Step 1: ダッシュボードページを作成

1. 左サイドバー最上部付近 → **＋ New page**
2. タイトル: `📊 営業ダッシュボード`
3. アイコン: 📊（ページタイトル左のアイコンをクリック）
4. ワークスペースの **トップ** にドラッグ（最よく開く場所）

### Step 2: 見出しと KPI エリア

1. ページ本文に `/heading` → **Heading 1**: `TOMS 営業ダッシュボード`
2. **Heading 3**: `主要指標（今月）`
3. 以下、KPI ごとに **Callout** ブロックで数値エリアを作成:

#### Callout の作り方（1 KPI 分）

1. `/callout` と入力 → Callout ブロック作成
2. アイコン: 📋（任意）
3. 本文:

```
今月見積
───
（下の Linked DB 件数を参照）
```

4. 6 つの Callout を **横並び**（ドラッグ or 列ブロック）に配置  
   → Notion では `/column` → **2 columns** を 3 回使い 2×3 配置

**6 つの Callout ラベル:**

| # | ラベル |
|---|--------|
| 1 | 今月見積件数 |
| 2 | 今月受注件数 |
| 3 | 今月売上 |
| 4 | 未請求件数 |
| 5 | 未入金件数 |
| 6 | 現調待ち件数 |

### Step 3: 今月見積一覧（Linked database）

1. `/linked` → **Linked view of database** → **見積DB**
2. ビュー名（リンクブロック左上）: `今月の見積`
3. 右上 **「⋯」** → **Filter** → **Add filter**:
   - `作成日` → **Is relative to today** → **This month**
4. **Sort** → `作成日` → Descending
5. 表示プロパティ: 見積名、見積番号、案件、税込合計、作成日
6. **件数確認**: テーブル下部の行数 = 今月見積件数 → Step 2 の Callout に記入

### Step 4: 今月受注件数用 Linked view

1. `/linked` → **案件管理DB**
2. ビュー名: `今月受注`
3. **Filter**:
   - `状態` **is** `受注`
   - **AND** `最終更新` **is relative to today** → **This month**  
     （または受注日プロパティがあればそれを使用）
4. 表示: 案件名、顧客名、案件番号

> 受注日プロパティが無い場合: 案件管理DB に **Date** 型 `受注日` を追加し、受注時に手動入力。

#### 受注日プロパティ追加手順

1. **案件管理DB** → **＋** → **Date** → 名前: `受注日`
2. 受注確定時に入力
3. ダッシュボード Filter: `受注日` **This month**

### Step 5: 今月売上（請求DB）

1. `/linked` → **請求DB**
2. ビュー名: `今月売上`
3. **Filter** → `請求日` **This month**
4. 表示プロパティ: 請求名、税込金額、入金確認
5. **Calculate**（列下部）:
   - `税込金額` 列をクリック → **Calculate** → **Sum**
6. Sum 値を Step 2 の「今月売上」Callout に記入

### Step 6: 未請求案件

1. `/linked` → **案件管理DB**
2. ビュー名: `未請求案件`
3. **Filter** → `状態` **is** `施工完了`
4. 表示: 案件名、顧客名、案件番号、工事予定日
5. **Sort** → `最終更新` Ascending（古い順 = 優先対応）

### Step 7: 未入金一覧

1. `/linked` → **請求DB**
2. ビュー名: `未入金`
3. **Filter**:
   - `入金確認` **is not checked**（OFF）
4. 表示: 請求名、税込金額、請求日、支払期限
5. **Sort** → `支払期限` Ascending

### Step 8: 現調待ち

1. `/linked` → **案件管理DB**
2. ビュー名: `現調待ち`
3. **Filter** → `状態` **is** `現調前`
4. 表示: 案件名、顧客名、現調日、担当者
5. **Sort** → `現調日` Ascending

### Step 9: 進行中案件カンボン

1. `/linked` → **案件管理DB**
2. ビュー名: `進行中カンバン`
3. レイアウト: **Board**
4. **Group by** → `状態`
5. **Filter** → `状態` **is not** `請求済`
6. カード: 案件名、顧客名、担当者

### Step 10: Aランク顧客

1. `/linked` → **顧客マスターDB**
2. ビュー名: `Aランク顧客`
3. **Filter** → `顧客ランク` **is** `A`
4. 表示: 顧客名、年間売上、最終工事日、注意事項

### Step 11: 今日の現調

1. `/linked` → **案件管理DB**
2. ビュー名: `今日の現調`
3. **Filter** → `現調日` **is** `Today`
4. 表示: 案件名、住所、担当者、電話番号

### Step 12: 2 列レイアウトで整理

1. `/column` → **2 columns**
2. 左列: 今月の見積 + 未請求案件
3. 右列: 未入金 + 現調待ち
4. その下に全幅: 進行中カンバン
5. 最下段 2 列: Aランク顧客 | 今日の現調

---

## 5. 毎日の更新ルーチン（30 秒）

```
1. 営業ダッシュボードを開く
2. 6 つの Callout 数値を各 Linked view の件数/Sum で更新
3. 未請求・未入金・現調待ち を確認
4. 今日の現調 で現場担当へ連絡（必要時）
```

> Phase 2 で KPI 自動更新スクリプトを導入予定。

## 6. 案件管理DB 追加プロパティ（受注日）

ダッシュボード精度向上のため、案件管理DB に以下を追加推奨:

| プロパティ | 型 | 用途 |
|-----------|-----|------|
| 受注日 | Date | 今月受注件数の Filter |
| 施工完了日 | Date | 未請求経過日数 |

### 受注日追加手順

1. **案件管理DB** → **＋** → **Date** → `受注日`
2. 案件状態を `受注` に変更する際、**受注日** に今日を入力
3. ダッシュボード `今月受注` ビューの Filter を `受注日` **This month** に変更
