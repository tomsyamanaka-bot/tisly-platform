## 2. 事前準備

### 2-1. CSV ファイルの確認

1. 本リポジトリの `data/` フォルダから CSV をダウンロード
2. Excel または Google スプレッドシートで開き、文字化けがないか確認
3. 文字化けする場合: メモ帳で開く → **名前を付けて保存** → エンコーディング **UTF-8**

### 2-2. Notion DB の準備

CSV をインポートする **前に** 対象 DB のプロパティ（列）を作成しておく。

| CSV 列名 | Notion プロパティ型 | 備考 |
|---------|-------------------|------|
| 顧客名 / 型式 / 見積タイトル | **Title** | CSV の最初の列 → Title にマッピング |
| 顧客区分 / 工事分類 / 作業内容 等 | **Select** | 選択肢を事前に登録 |
| 単価補正率 / 標準単価 / 見積金額 等 | **Number** | 形式（Yen 等）はインポート後に設定 |
| 請求締日 / 受注結果 等 | **Select** | 選択肢を事前に登録 |
| 支払条件 / 備考 / 工事項目 等 | **Text** | — |
| 提出日 / 最終工事日 | **Date** | 形式: `YYYY-MM-DD` |
| 対応エリア | **Multi-select** | カンマ区切りで複数指定可 |
| 年間売上 / 粗利率 | **Number** | — |

## 3. インポート手順（共通）

### Step 1: インポート画面を開く

**方法 A — DB 内から（推奨）**

1. 対象 DB（例: 顧客マスターDB）を開く
2. テーブル右上 **「⋯」**（三点メニュー）をクリック
3. **Merge with CSV** を選択

**方法 B — 新規 DB として**

1. 左サイドバー → **Import**
2. **CSV** を選択
3. ファイルをアップロード
4. 新規 DB として作成される（プロパティ型の再設定が必要）

> **方法 A を推奨**。既存 DB に列を追加済みの状態でマージする。

### Step 2: CSV ファイルを選択

1. **Upload** または **Choose a file** をクリック
2. PC 上の CSV ファイルを選択
3. プレビュー画面が表示される

### Step 3: 列マッピング

1. CSV の各列が Notion プロパティに対応していることを確認
2. 1 列目（顧客名 / 型式 / 見積タイトル）→ **Title** プロパティにマッピング
3. 未マッチの列 → **「＋ New property」** で新規作成、または既存列に割当
4. 不要な列 → **Don't import** を選択

> **[📸 スクショ]** 列マッピング画面  
> 保存先: `screenshots/import_column_mapping.png`

### Step 4: インポート実行

1. **Import** ボタンをクリック
2. 処理完了まで待つ（100 件で 10〜30 秒程度）
3. DB 内にレコードが追加されたことを確認

### Step 5: インポート後の確認・修正

| 確認項目 | 対処 |
|---------|------|
| Select 値が空 | CSV の値と Select 選択肢が完全一致しているか確認（全角/半角） |
| Number が 0 になる | カンマ区切り（55,000）を除去して再インポート |
| Date がずれる | `YYYY-MM-DD` 形式に修正 |
| Multi-select が 1 つしか入らない | カンマ区切り `茨城県北,茨城県央` 形式を確認 |
| 重複レコード | フィルターで確認 → 不要行を削除 |

## 5. CSV インポートできないもの

| 項目 | 理由 | 代替方法 |
|------|------|---------|
| Relation（案件/顧客/見積 等） | Notion CSV 非対応 | インポート後に手動リンク |
| Rollup | 計算プロパティ | DB 構築時に Formula/Rollup 設定 |
| Formula | 計算プロパティ | DB 構築時に設定 |
| Unique ID（案件番号等） | 自動採番 | レコード作成時に自動付与 |
| Files & media（写真/PDF） | バイナリ非対応 | 手動アップロード |
| Checkbox | CSV 対応は限定的 | 手動設定 or インポート後一括更新 |

## 6. トラブルシューティング

### 文字化け

```
原因: Shift-JIS / CP932 で保存されている
対処:
  1. メモ帳で CSV を開く
  2. ファイル → 名前を付けて保存
  3. エンコーディング: UTF-8
  4. 保存して再インポート
```

### Select 値が空白になる

```
原因: CSV の値と Select 選択肢が不一致
例:  CSV = "元請Ａ"（全角A） vs Select = "元請A"（半角A）
対処: CSV または Select 選択肢を完全一致させる
```

### 数値が正しくインポートされない

```
原因: カンマ区切り "55,000" / 円記号 "¥55,000"
対処: CSV からカンマ・記号を除去（55000）
      インポート後に Number format → Yen を設定
```

### 日付がずれる

```
原因: MM/DD/YYYY vs DD/MM/YYYY の解釈差
対処: CSV の日付を YYYY-MM-DD 形式に統一
      例: 2025-03-15
```

### 重複インポート

```
原因: 同じ CSV を 2 回インポート
対処:
  1. 重複行をフィルターで特定
  2. 行を選択 → Delete
  3. または DB を新規作成し直して 1 回だけインポート
```

## 7. 再インポート（やり直し）

1. 対象 DB の全レコードを選択（テーブル左上チェックボックス）
2. 右クリック → **Delete** で全削除
3. Select 選択肢・プロパティ型はそのまま
4. 上記 Step 1 から再インポート

> **注意**: Relation / Rollup / Formula プロパティは削除されない。データ行のみ削除。
