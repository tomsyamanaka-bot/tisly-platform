# 板橋自宅（TOMS001）顧客カルテ

社内画面 `/app/security-v1` で板橋自宅を選ぶと、保存済み設定から「現在の設定サマリー」を日本語で出す。テスター（TESTER001）は同じ現場の画面ミラーで、実機の配線はこのカルテのまま。設定を変えたらこの文章も更新する。既存の端子表は消さない。

## ハードウェアと使っているセンサー

主装置は `rp2350-itabashi-main-01`。子機はない。物件は `HOME-JP-ITABASHI-LIVE` / `SEC-JP-ITABASHI-LIVE`。

DI1 は駐車場（外周）、DI2 はガレージ。防犯ライトは DO2 と DO3 を一緒に点ける。DO1 は電気錠のワンショットで、防犯ライトには使わない。ドアホンはアイリスオーヤマ TD-SM5030CT-BSH。録画は H.View NVR（`192.168.1.80`）の玄関・勝手口・駐車場。

## 顧客画面の出し分け

顧客の警報は場所と種類の文章で、カメラ映像は埋め込まない。間取りのカメラピンも出さない。社内の通信カードと顧客の安心ステータスは分けてある。

## いまの閾値

保存済みの値（画面のサマリーが読むもの）は、点灯時間帯 18:00〜06:00、点灯維持 75 秒、駐車場の感応度 80ms、ガレージの感応度 150ms。昼間もセンサー連動でライトが動くテスト設定がオン。オフにすると、時間帯の外は通知のみになる。

盤内温度は 45℃で注意、50℃は社内だけへ先に知らせ、60℃で警告。ファームの版は 1.6.x で、豊島邸の 1.2.x とは別。初期カタログの点灯 45 秒・感応度 100ms は、保存値で上書き済みの読み取り結果とは別に残す。

サマリーに「駐車場」「ガレージ」といった固定文はない。画面は保存した秒数と、その物件のセンサー名から文を作る。
