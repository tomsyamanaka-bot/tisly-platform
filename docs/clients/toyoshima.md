# 豊島邸（TOYOSHIMA001）顧客カルテ

社内画面 `/app/security-v1` で豊島邸を選ぶと、保存済み設定から「現在の設定サマリー」を日本語で出す。このファイルは仕様の記録で、現場の JSON は上書きしない。設定や顧客画面の出し分けを変えたら、この文章も一緒に更新する。

## ハードウェアと使っているセンサー

母屋の主装置は `rp2350-toyoshima-main-01`、はなれの子機は `rp2350-toyoshima-detached-01`。物件は `HOME-JP-TOYOSHIMA` / `SEC-JP-TOYOSHIMA-001`。

母屋は赤外線ビームを2本使う。DI1 は外周（遠）、DI2 は建物至近（近）。出力は DO1 が防犯ライト1、DO2 が防犯ライト2、DO3 がフラッシュ。はなれは道路側 DI1 と通路側 DI2、ライト DO1 とパトライト DO2。はなれ DO3 はラベルだけで、制御では使っていない。録画は H.View NVR（`192.168.10.50`）の玄関・道路側・通路側。

## 顧客画面の出し分け

顧客の警報は時刻とセンサー名だけで、カメラ静止画は出さない。ライブ共有の設定カードは社内画面だけにある。顧客の通知切替に出すのは母屋の外周と至近だけで、はなれの道路側・通路側は出さない。1F と 2F は無効なので、顧客の階タブにも出ない。

## いまの閾値

保存済みの値（画面のサマリーが読むもの）は、点灯時間帯 18:00〜06:00、点灯維持 45 秒、フラッシュ 15 秒で起動する、感応度は外周・至近・はなれとも 100ms、連動は遠近2段階の常時点灯。昼間もセンサー連動でライトが動くテスト設定がオン。

`forceRelayTest` をオフにすると、サマリーの昼は「通知のみ」になる。`flashEnabled` をオフにすると「至近検知時はフラッシュを起動しません」になる。外周のあと 120 秒以内の至近を段階侵入とみなす初期値は残っている。

サマリーの文言は物件名では固定しない。保存した時刻・秒数・感応度と、カタログ上のセンサー名からその場で組み立てる。社内の `/app/security` で豊島邸を選んだときも、フロア画面を隠したあとにサマリーを残す。顧客の `/customer` と `/customer/security` には出さない。

## 母屋の点灯（2026-10-21）

遠（DI1）はフラッシュ（DO3）を点灯し、ライト1（DO1）は常時点灯する。近（DI2）はフラッシュ（DO3）を点灯し、ライト1（DO1）とライト2（DO2）を 0.5 秒間隔で点滅する。点滅はメインループを止めない。設定した点灯秒数が過ぎたら、点灯も点滅も止めて DO1・DO2・DO3 を消す。日中で「昼間でもセンサー連動」がオフのときは、センサーが反応してもリレーを出さず通知だけにする。はなれと板橋の点灯、威嚇点滅モード `two_stage_blink` の点灯パターンはこの変更に含めない。OTA は豊島邸の実機だけが次の心拍で取り込む。配信する版は `toyoshima_security.py` と `config_toyoshima.py` に書いてある版と一致させる。実機の申告がその文字列と一致するまで、心拍のたびに更新を返す。いま動いている実機は、最初の応答では `boot.py` と `lib/tisly_ota.py` だけを受け取り、その次の通信で残りのスクリプトを分割して書く。

## 母屋の点灯（2026-10-22）

遠近2段階は、遠でライト1だけ点灯し、遠のあと近でライト1・ライト2・フラッシュをすべて点灯する。威嚇点滅は、遠でライト1だけ点滅し、遠のあと近で3つとも点滅する。すぐ全点灯は、遠でも遠のあと近でも3つとも点灯する。通知のみは、昼も夜もライトとフラッシュを出さない。遠センサーが反応せず近だけ反応したときは、通知のみ以外ならライト1とライト2だけを、防犯ライト点灯維持時間のあいだ点灯する。フラッシュは出さない。点灯時間帯は開始が終了より遅くても夜間として扱う。警戒を切ったときと一時停止中は、ライトとフラッシュを出さない。

顧客の詳細設定は、モード・点灯時間・通知条件を変えても、その場では保存しない。「設定変更を確定する（保存）」でまとめて保存し、実機へ反映する。防犯ライト手動動作の5ボタン（ライト1、ライト2、一括ON、一括OFF、フラッシュ威嚇テスト）だけは押した瞬間に命令を送る。通知条件の表示名は遠センサーと近センサー。お客様トップのご契約の機能は TiSLY Security だけにし、ご利用メニューは出さない。Push通知の登録はお客様トップの「Push通知を登録・購読する」だけに置く。テスター用の「実機の通知」バーは出さない。お知らせから「請求書が届きました」「見積書が届きました」は出さない。5分ハートビートは死活・温度・版・IPだけで、外周と至近の検知通知は出さない。検知はセンサーの立上りだけ。未結線の入力は内部プルアップで非検知側に固定する。

## センサー名と発報確認（2026-10-22）

動作履歴と Push の DI1 は「外側・遠センサー検知」、DI2 は「建物側・近センサー検知」。過去に保存された駐車場センサー、外周で接近検知、遠センサー、ガレージセンサー、建物至近で侵入検知、近センサーなどの文言は、画面に出すときにこの2つの名前へ読み替える。新しく保存する通知も同じ名前。お客様の赤い「発報があります」カードにある「確認した」は、いまの警報だけを消し、緑の「安全確認：異常なし」に戻す。これまでの発報件数と履歴は残す。

## 威嚇点滅の消灯と作業灯（2026-10-24）

遠近2段階（威嚇点滅）は、発報から防犯ライト点灯維持時間を数える。時間が来たら点滅を止め、ライト1・ライト2・フラッシュをすべて消す。センサーが入りっぱなしでも消す。両方のセンサーが戻るまで、同じ検知では点灯し直さない。

遠センサーの直近履歴が無いときに近センサーだけが先に反応したときは、威嚇点滅にしない。ライト1とライト2だけを点滅なしで点け、フラッシュは連動しない。点灯維持時間が来たら消す。遠のあと、外周タイムアウト以内の近は従来どおり3出力を点滅する。

お客様の `/customer` では版番号を出さず、「最新状態です」か「更新があります（自動更新待機中）」だけを出す。豊島邸の目標版は `1.2.29`。龍ヶ崎店や板橋の版が上がっても、この目標は動かさない。社内の `/app` は実機バージョンとクラウド側設定バージョンを数値のまま出す。OTA は豊島邸のスクリプトだけを配る。
