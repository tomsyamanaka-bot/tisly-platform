# 豊島邸（TOYOSHIMA001）顧客カルテ

社内画面 `/app/security-v1` で豊島邸を選ぶと、保存済み設定から「現在の設定サマリー」を日本語で出す。このファイルは仕様の記録で、現場の JSON は上書きしない。設定や顧客画面の出し分けを変えたら、この文章も一緒に更新する。

## ハードウェアと使っているセンサー

母屋の主装置は `rp2350-toyoshima-main-01`、はなれの子機は `rp2350-toyoshima-detached-01`。物件は `HOME-JP-TOYOSHIMA` / `SEC-JP-TOYOSHIMA-001`。

母屋は赤外線ビームを2本使う。DI1 は外周（遠）、DI2 は建物至近（近）。出力は DO1 が防犯ライト1、DO2 が防犯ライト2、DO3 がフラッシュ。はなれは道路側 DI1 と通路側 DI2、ライト DO1 とパトライト DO2。はなれ DO3 はラベルだけで、制御では使っていない。録画は H.View NVR（`192.168.10.50`）の玄関・道路側・通路側。

## 顧客画面の出し分け

顧客の警報は時刻とセンサー名だけで、カメラ静止画は出さない。ライブ共有の設定カードは社内画面だけにある。顧客の通知切替に出すのは母屋の外周と至近だけで、はなれの道路側・通路側は出さない。1F と 2F は無効なので、顧客の階タブにも出ない。

## いまの閾値

保存済みの値（画面のサマリーが読むもの）は、点灯時間帯 18:00〜06:00、点灯維持 45 秒、フラッシュ 15 秒で起動する、感応度は外周・至近・はなれとも 100ms、連動は遠近2段階の常時点灯。昼間もセンサー連動でライトが動くテスト設定がオン。

`forceRelayTest` をオフにすると、サマリーの昼は「通知のみ」になる。`flashEnabled` をオフにすると「至近検知時はフラッシュを起動しません」になる。外周のあと 120 秒以内の至近を段階侵入とみなす初期値は残っている。

サマリーの文言は物件名では固定しない。保存した時刻・秒数・感応度と、カタログ上のセンサー名からその場で組み立てる。社内の `/app/security` で豊島邸を選んだときも、フロア画面を隠したあとにサマリーを残す。顧客の `/customer` と `/customer/security` には出さない。

## 母屋の点灯（2026-10-21）

遠（DI1）はフラッシュ（DO3）を点灯し、ライト1（DO1）は常時点灯する。近（DI2）はフラッシュ（DO3）を点灯し、ライト1（DO1）とライト2（DO2）を 0.5 秒間隔で点滅する。点滅はメインループを止めない。設定した点灯秒数が過ぎたら、点灯も点滅も止めて DO1・DO2・DO3 を消す。日中で「昼間でもセンサー連動」がオフのときは、センサーが反応してもリレーを出さず通知だけにする。はなれと板橋の点灯、威嚇点滅モード `two_stage_blink` の点灯パターンはこの変更に含めない。OTA は豊島邸の実機だけが次の心拍で取り込む。配信する版は `toyoshima_security.py` と `config_toyoshima.py` に書いてある版と一致させる。実機の申告がその文字列と一致するまで、心拍のたびに更新を返す。
