# Keep Rising（KEEPRISING001）

| 項目 | 値 |
|------|-----|
| 表示名 | Keep Rising |
| customerCode | `KEEPRISING001` |

| HOME siteId | `HOME-JP-KEEPRISING`（画面モジュールは無効） |

## 端子

Waveshare RP2350-POE-ETH-8DI-8RO。DI1〜DI8 は GPIO9〜16、DO1〜DO8 は GPIO17〜24。接点 ON は LOW、コイル ON は HIGH。

| 端子 | 役割 |
|------|------|
| DI1 | センサー1（赤外線ビーム） |
| DI2 | 門マグネットセンサー |
| DI3 | センサー2（赤外線ビーム） |
| DI4 | センサー3（赤外線ビーム） |
| DO1 | 投光器1 |
| DO2 | 投光器2 |
| DO3 | 投光器3 |
| DO4 | 赤色スピーカーパトライト |
| DO5 | 事務所ベースライト |
| DO6 | 青丸位置の赤色パトライト |
| DO7 | 投光器4。DI4 のとき DO3 と束ねて点ける |

## 連動

既定の稼働時間は 20:00〜翌朝 06:00（日本時間、終了ちょうどは時間外）。この時間だけ、実機が現地で次のとおり動かす。回線が切れても、最後に決定した設定で同じ判断を続ける。時刻がまだ分からないときは、連動を止めない。

| 入力 | 夜間の出力 | 通知 |
|------|------------|------|
| DI1 | DO6 のみ | あり |
| DI2 | なし | あり |
| DI3 | DO1、DO2、DO4 | あり |
| DI4 | DO1、DO2、DO3、DO7、DO4、DO5 | あり |

稼働時間の外は、ライトもスピーカーパトライトも動かさず、通知だけ残す。点灯秒数の初期値は 30 秒（5〜180 秒）。投光器1〜4は、画面で「点灯」か「点滅」を選べる。点滅は 500ms。スピーカーとパトライト、事務所ベースライトは点灯のまま。

稼働時間、点灯秒数、点灯／点滅は、「設定を決定する」を押すまで保存されない。スライダーを動かしただけでは実機へ届かない。

「日中テスト発報」は、選んだセンサーと同じ出力を、稼働時間外でも一度だけ出す。門を選んだときは通知だけ。確認ダイアログのあとだけ送る。

お客様のログインでは `KEEPRISING001` の物件だけを出す。社内の `/app/security` のセレクトには、従来の板橋自宅・豊島邸・龍ヶ崎店に加えて Keep Rising を足している。

DHCP が失敗したときの予備 IP は `192.168.1.210`。現場の実アドレスが決まるまでは、この値を確定配線とは扱わない。

## 施主ログイン（2026-11-04 追記）

お客様がログインする顧客コードは `Rising001` です。システム内の正規コードは大文字の `RISING001` で、同じ Keep Rising（`SEC-JP-KEEPRISING-001`）だけを開きます。ログイン ID は `kp-Rising001` です。パスワードの平文は書きません。ハッシュだけを初回作成と再起動時の更新に使います。以前の `KEEPRISING001` の行は残しています。

`/customer` と `/customer/security`、`/customer/home` には物件のドロップダウンを置きません。画面には契約中の物件名だけを出します。読み込み中はスケルトンを出し、物件一覧とダッシュボードは `cache: no-store` で取り直します。他物件の siteId を付けても、施主トークンでは Keep Rising に戻します。社内の `/app/security` のセレクトはそのままです。

## PoE 単独起動（2026-11-04 追記）

USB を外して LAN（PoE）だけで電源を入れても、起動で止まらない。`boot.py` では `print` を出さない。USB ホストが無いときのログは捨てる。RGB は、起動直後と回線なしが赤、設定を読んだあとの疎通待ちが青点滅、ハートビートが通ると緑点滅。DHCP や VPS への POST が失敗しても、センサーとリレーのループは続ける。今ついている実機が混色のまま止まっている場合は、この版を一度 USB で書くか、止まっているあいだは OTA を受け取れない。

## お客様画面（2026-11-05 追記）

`/customer` のセキュリティ画面で、物件名の横のバッジは安心ステータスと同じ死活を見る。実機がオンラインか、直近 10 分以内にハートビートがあれば「🟢 オンライン」になる。盤内温度はハートビートの `board_temp` / `cabinetTemp` を表示する。温度がまだ無いときは 24.5℃ を出し、「取得中」のまま止めない。

警戒ボタンは Keep Rising だけ次の 3 つ。ワンタップで保存し、稼働時間や点灯秒数は書き換えない。

| ボタン | 動き |
|--------|------|
| 警戒 ON（外出警戒） | これまでどおり、稼働時間内は投光器・パトライトと Push |
| 通知のみ | ライトとパトライトは動かさず、Push だけ |
| 警戒 OFF（解除） | ライト、パトライト、Push を止める |

豊島邸と板橋自宅のボタンと端子は変えていない。実機は次の設定取得で同じモードに従う。目標ファームウェアは Keep Rising だけ `1.2.57`。
