# 営業デモの操作手順

## 入口

**`/sales`** — 商談・展示会で使う営業専用画面

## 推奨フロー（15分）

1. **デモを初期化** — 商談開始前にデータを揃える
2. **TiSLY でできること** カードで価値を説明
3. **導入前 / 導入後** で課題と解決を対比
4. **侵入を発生させる** → 自動で図面プレビューへ（外周へスクロール）
5. **照明の再起動デモ** — 出動削減の例
6. **現調から見積を作る** → 案件管理画面を別タブで見せる
7. **KPI を CSV で保存** — 経営向け資料のたたき台
8. **見積サンプル（戸建て / 民泊 / 工場）** — PDFプレビュー（HTML）
9. **Google TV / PWA 導線** — 誰がどの画面を使うか説明

## デモ操作ボタン一覧

| ボタン | API | 説明 |
|--------|-----|------|
| 侵入を発生させる | `POST .../notifications/intrusion` | 通知 + 図面へ遷移 |
| 通信機の異常を発生させる | `POST .../notifications/esp_fault` | 黄色表示の例 |
| 照明の再起動デモ | `POST .../shelly-reboot` | WARNING → ONLINE |
| 現調から見積を作る | `POST .../ai-estimate` | mock フロー + Business |
| お知らせを送る | `POST .../notifications/maintenance_due` | プッシュ例 |
| デモを初期化 | `POST .../reset` | フルリセット |

## 顧客の切り替え

画面上部の「お客様の例」で `TOMS001` / 民泊 / 工場 などを選択してから操作する。

- 手動のみ / 毎朝 6:00 / 平日 8:00 を PUT `/api/demo-kit/reset-schedule` に保存
- 実際の cron 実行は未接続（`nextRunAt` の表示のみ）
