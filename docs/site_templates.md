# 現場テンプレート（Phase 101–120）

各テンプレは営業デモ・実機設計の出発点です。  
`site_id` は英小文字スラッグ、`device_id` は `docs/device_id_rules.md` に従います。

---

## 戸建住宅（HOME）

| 項目 | 内容 |
|------|------|
| **標準デバイス** | ESP-HOME-001, RP-HOME-001（任意）, TV-LOBBY-001 |
| **標準センサー** | 赤外×2, 人感×2, 窓×2, 非常停止 |
| **標準出力** | 100V ライト×2, パト, ブザー |
| **通知ルール** | 侵入→alarm Push+Discord / 人感→warning |
| **TV 表示** | 警戒状態, 最新警報, AI Risk |
| **QNAP 保存** | 全日イベント JSON, 週次レポート |

## テンプレ適用 API

```bash
# 例: 車屋デバイス登録
curl -X POST http://localhost:3080/api/devices/register \
  -H "Content-Type: application/json" \
  -d '{"deviceId":"PLC-SHOP-001","deviceType":"plc","siteId":"carshop-night","label":"車屋夜間PLC"}'
```
