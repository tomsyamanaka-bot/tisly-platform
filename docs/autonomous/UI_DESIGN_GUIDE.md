# UI デザインガイド（TiSLY 全 PWA 標準）

一般のお客様にも見せられる、やさしく見やすい画面を作るためのルールです。

## デザイン方針

- **やさしい色** — 白〜薄いグレー背景、柔らかい青・緑をメインに
- **大きいボタン** — 指で押しやすい（最低 44px 高さ）
- **写真カード中心** — 文字より画像で伝える
- **アイコン中心** — 絵文字・シンプルアイコンで機能を示す
- **1画面1目的** — 迷わせない。戻るボタンは常に左上
- **難しい言葉を使わない** — 社内用語は避けるか短い説明を添える
- **業者用語には説明** — 「現調」「見積」などに一行の補足
- **エラー文** — 原因より先に「次に押すボタン」を出す
- **画面の分離** — 一般客向けと社内向けを分ける

## 色味

| 用途 | 色 |
|------|-----|
| 背景 | 白 `#ffffff` 〜 薄いグレー `#f6f8fa` |
| メイン（青） | やさしい青 `#4a90d9` |
| メイン（緑） | やさしい緑 `#5cb87a` |
| 注意 | 柔らかいオレンジ `#e8a54b` |
| 危険 | 強すぎない赤 `#d9534f` |
| カード | 角丸 12px、余白多め、薄い影 |

共有 CSS: `server/public/css/tisly-friendly-ui.css`

## 文言ルール

### NG → OK 例

| NG（技術用語） | OK（やさしい日本語） |
|----------------|----------------------|
| `estimate_pending` | 見積もり作成待ち |
| `workflow_status` | 今の進み具合 |
| `materials` | 使う部材 |
| `finalize` | 見積もりを確定 |
| `surveying` | 現場調査中 |
| `handoff` | 見積へ送る |
| `items_json` | 見積の内訳 |
| `PDF生成済` | 見積書の準備ができました |

### 業者用語の補足例

| 用語 | 補足文 |
|------|--------|
| 現調 | お客様の現場を見に行く記録 |
| 見積 | お仕事の料金をまとめたもの |
| 部材 | カメラや配線など使うもの |
| TOMS | 社内の見積データ形式（お客様には見せない画面で使用） |

## エラー表示

```
❌ 保存できませんでした

もう一度「保存する」ボタンを押してください。
それでもダメなときは、画面上部の「戻る」から一覧に戻れます。
```

原因の技術詳細は社内向け画面のみ表示。

## 画面タイプ

| タイプ | 対象 | 例 |
|--------|------|-----|
| 一般客向け | お客様・施主 | 顧客ポータル、見積 PDF プレビュー |
| 社内実務向け | 現調担当・見積担当 | 現調 v1、見積 v1 |
| 社内管理向け | 管理者・オペレータ | App Hub デプロイ系、管理画面 |

一般客向け画面では英語・コード名・ステータスコードを出さない。

## カード UI パターン

```
┌─────────────────────────┐
│ 📷  写真メモ            │
│ ┌─────┐                 │
│ │ img │  玄関ドア正面    │
│ └─────┘  2026-06-08     │
└─────────────────────────┘
```

- 写真はサムネイル 80px 以上
- 一覧はタップで詳細へ
- 空のときは「まだありません」+ 追加ボタン

## ボタン

| 種類 | 見た目 |
|------|--------|
| メイン操作 | 大きい・塗りつぶし・緑 or 青 |
| 副操作 | 白背景・枠線 |
| 危険操作 | 柔らかい赤・確認ダイアログ必須 |

## 禁止事項

- AI っぽい硬い文章（「〜を実行します」「〜が完了しました」の連発）
- 英語のステータスをそのまま表示
- 1画面に10個以上の入力欄
- 暗い背景 + 小さい文字（お客様向け）
