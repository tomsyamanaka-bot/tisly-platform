# TOMS Notion 構築チェックリスト

> **Phase 1.6 — 実構築フェーズ**  
> 半日（4〜6時間）で Notion 上に TOMS 業務管理システムを構築するためのチェックリスト

---

## 使い方

1. 上から順番に進める（Relation の依存関係があるため順序を守る）
2. 各項目の `[ ]` を `[x]` に変更して進捗管理
3. 詳細手順は [notion_build_step_by_step.md](./notion_build_step_by_step.md) を参照
4. CSV インポートは [import_procedure.md](./import_procedure.md) を参照

## 構築順序サマリー

```
1. 顧客マスターDB  ← CSV インポート可
2. 案件管理DB      ← Relation 先が必要
3. 現調DB          ← 案件管理DB が必要
4. 単価マスターDB  ← CSV インポート可 → 現調DB の Relation 完成
5. 見積DB
6. 請求DB
7. 工事写真DB
8. 見積ライブラリDB ← CSV インポート可（Relation は手動）
9. ダッシュボード   ← 全 DB 完成後
```
