## 2. デモ台本（10 分）

### Step 1 — 導入（1 分）

**話すこと:**

> 「TiSLY Lite は、お客様のスマホにリアルタイムで防犯通知が届くシステムです。専用アプリのインストールは不要で、ブラウザの PWA だけで動きます。」

**操作:** PWA を開き、トップ画面を見せる。

---

### Step 2 — 接続状態の確認（1 分）

**話すこと:**

> 「現場の制御盤とクラウドが常時つながっています。今、デモ機は online と表示されています。」

**操作:**

1. 「RP2350 接続状態」カードで **online** を指差す
2. `lastSeen`（接続時刻）が直近であることを示す
3. ファームウェア版 `1.4.0-remote-test-phase6` を確認

---

### Step 3 — 遠隔制御デモ（2 分）

**話すこと:**

> 「スマホから現場のリレーを遠隔操作できます。警報器や照明の連動にも使えます。」

**操作:**

1. **CH1 ON** → 約 3 秒以内にリレー LED 点灯（実機あり）または Push「CH1 ON」
2. **CH1 OFF** → Push「CH1 OFF」
3. （時間があれば）CH8 ON/OFF も 1 回実演

**Push が届いたら:** 「状態が変わると即座にスマホに通知が来ます」と説明。

---

### Step 4 — 防犯シナリオ（4 分）★ メイン

**話すこと:**

> 「警戒モードでは、センサーが反応するとすぐに通知されます。解除中はログだけ残し、誤報通知は送りません。」

#### 4-A 警戒 ON

1. **警戒ON** をタップ
2. iPhone に Push「**警戒ON**」が届くことを見せる
3. 「イベント履歴」に `arm` が追加されたことを示す

#### 4-B 侵入検知（配線なし）

1. **侵入シミュレーション** をタップ
2. Push「**侵入検知 / 駐車場センサー**」を見せる
3. イベント履歴に `intrusion` が記録されたことを示す

**話すこと:**

> 「展示会や商談では配線なしでこのボタン一つで侵入を再現できます。現場では駐車場センサーなどが DI1 に接続されます。」

#### 4-C 実機 DI（任意・実機がある場合）

1. DI1 接点を ON → 同様の Push
2. DI1 OFF → 復帰通知（設定による）

#### 4-D 警戒 OFF

1. **警戒OFF** をタップ → Push「警戒OFF」
2. DI1 を再度 ON（実機 or シミュレーション）
3. **Push は来ない** がイベント履歴には `input` として残ることを示す

**話すこと:**

> 「解除中はセンサーの動きは記録だけして、通知は送りません。営業時間外の誤報を減らせます。」

---

### Step 5 — センサー一覧・まとめ（2 分）

**操作:**

1. DI1〜DI8 カードをスクロール（駐車場センサー・ガレージセンサー・勝手口・非常ボタン…）
2. 通知履歴を見せる（Push 送信分の一覧）

**話すこと:**

> 「センサー名称は現場に合わせて変更できます。本番導入時は MQTT 化・マルチ拠点・顧客別認証を Phase 7 で進める予定です。今日お見せしたのは TiSLY Lite の RC1 デモ版です。」

## 4. 配線なしモード（RP2350 故障時）

RP2350 が offline でも以下は実施可能（VPS のみ動作）:

| 可能 | 不可 |
|------|------|
| 警戒 ON/OFF + Push | CH 実機制御 |
| 侵入シミュレーション + Push | DI 実機状態表示 |
| eventHistory / notificationHistory | heartbeat / online 表示 |

**説明例:** 「本日は通信モジュールの再起動中ですが、クラウド側の防犯ロジックはこのように動作します。」

## 5. よくある質問（FAQ）

| 質問 | 回答例 |
|------|--------|
| アプリは必要？ | 不要。Safari で URL を開きホーム画面に追加するだけ |
| Android は？ | PWA + Web Push 対応。デモは iPhone 推奨 |
| 月額費用は？ | 本番は VPS + 回線 + 機器。デモ版は社内 VPS |
| 何台まで？ | RC1 は 1 台。複数拠点は Phase 7 |
| 停電時は？ | RP2350 再起動後、約 60 秒で online 復帰 |
| 他社カメラ連携？ | Phase 7 候補（QNAP アーカイブ等） |

## 7. トラブルシューティング

| 症状 | 対処 |
|------|------|
| Push が来ない | PWA ホーム画面追加 · 通知許可 · VAPID 設定確認 |
| 403 Forbidden | トークン不一致。PWA のトークン再入力 |
| CH が動かない | RP offline 確認 · 3 秒待機 · `GET /debug` |
| 警戒が戻る | 通常は永続化。VPS 再起動直後は DISARM 初期値 |
| 初回 DI で Push なし | 正常（ベースライン確立）。2 回目以降で通知 |
