# 顧客管理強化 — 設計・構築手順

> **TOMS Phase 1.5** — 顧客マスターDB への項目追加と運用強化  
> 最終更新: 2026-05-31

---

## 1. 目的

Phase 1 の顧客マスター（区分・補正率）に加え、営業・経営判断に必要な情報を集約する。

| 追加項目 | 用途 |
|---------|------|
| 顧客ランク（A/B/C） | 優先対応・値引き判断 |
| 年間売上 | 重要顧客の把握 |
| 最終工事日 | 休眠顧客のフォロー |
| 紹介元 | 紹介ルート分析 |
| 対応エリア | 出張可否・担当割当 |
| 注意事項 | 現場・請求時の注意喚起 |
| 過去案件数 | 取引実績の可視化 |

---

## 2. Phase 1 からの追加プロパティ

既存の顧客マスターDB（Phase 1）に **以下を追加** する。

| プロパティ名 | Notion型 | 必須 | 説明 |
|-------------|----------|------|------|
| 顧客ランク | **Select** | ○ | A / B / C |
| 年間売上 | **Number** | △ | 円。Rollup で自動集計も可 |
| 最終工事日 | **Date** または **Rollup** | △ | 最新案件の施工完了日 |
| 紹介元 | **Text** または **Select** | △ | 紹介者・紹介会社 |
| 対応エリア | **Multi-select** | △ | 対応可能地域 |
| 注意事項 | **Text** | △ | 請求・現場注意点 |
| 過去案件数 | **Rollup** | — | 関連案件の Count |

### 2.1 既存プロパティ（Phase 1・変更なし）

| プロパティ名 | Notion型 | 説明 |
|-------------|----------|------|
| 顧客名 | Title | 正式名称 |
| 顧客区分 | Select | 一般 / 管理会社 / 元請A 等 |
| 単価補正率 | Number | 見積計算用 |
| 請求締日 | Select | 月末 / 20日 等 |
| 支払条件 | Text | 翌月末払い 等 |
| 備考 | Text | 社内メモ |
| 関連案件 | Relation → 案件管理DB | 双方向 |

### 2.2 顧客ランク（Select）定義

| ランク | 基準（目安） | 運用 |
|--------|------------|------|
| **A** | 年間売上 500 万円以上、または月 2 件以上の継続取引 | 最優先対応・定期フォロー |
| **B** | 年間売上 100〜500 万円、年数回の取引 | 標準対応 |
| **C** | 年間売上 100 万円未満、スポット取引 | 効率重視対応 |

> 基準は TOMS 運用に合わせて調整可能。

### 2.3 対応エリア（Multi-select）例

```
茨城県北
茨城県央
茨城県南
千葉県
埼玉県
東京都
その他
```

## 3. 自動集計プロパティ（Rollup / Formula）

### 3.1 過去案件数

1. 既存の `関連案件` Relation を利用
2. 新規 **Rollup** プロパティ:

| 設定項目 | 値 |
|---------|-----|
| 名前 | `過去案件数` |
| Relation | `関連案件` |
| Property | `案件名`（任意のプロパティ） |
| Calculate | **Count all** |

### 3.2 最終工事日（Rollup）

1. **Rollup** プロパティを追加:

| 設定項目 | 値 |
|---------|-----|
| 名前 | `最終工事日` |
| Relation | `関連案件` |
| Property | `工事予定日` または 案件の完了日プロパティ |
| Calculate | **Latest date** |

> 案件管理DB に `施工完了日` を追加している場合はそちらを使用。

### 3.3 年間売上（Rollup — 請求DB 経由）

請求DB が案件経由で顧客に紐づく場合:

**方法 A（手動更新）**: `年間売上` を Number 型で手動入力（月末更新）

**方法 B（Rollup — 推奨）**:

1. 顧客マスターDB に **Relation** → 請求DB を追加（請求DB 側に顧客 Relation が必要）
2. または案件管理DB 経由で請求を Rollup

簡易版（Phase 1.5 推奨）:

1. `年間売上` = **Number**（手動）
2. 月末に請求DB から集計して更新
3. Phase 2 以降で Formula / 外部連携により自動化

## 4. Notion 構築手順（初心者向け・詳細）

### Step 1: 顧客マスターDB を開く

1. 左サイドバー → **マスター** → **顧客マスターDB**
2. **全顧客** テーブルビューを表示

### Step 2: 顧客ランクを追加

1. テーブル右上 **「＋」**
2. **Select** を選択
3. プロパティ名: `顧客ランク`
4. **Edit property** → **Add options**:

| Option | Color |
|--------|-------|
| A | Red |
| B | Yellow |
| C | Gray |

5. **Done**

### Step 3: 年間売上を追加

1. **＋** → **Number**
2. 名前: `年間売上`
3. **Edit property** → Number format: **Yen**

### Step 4: 最終工事日を追加

#### 手動入力版

1. **＋** → **Date** → 名前: `最終工事日`

#### Rollup 自動版（案件がある場合）

1. **＋** → **Rollup**
2. 名前: `最終工事日`
3. Relation: `関連案件`
4. Property: `工事予定日`（または `最終更新`）
5. Calculate: **Latest date**

### Step 5: 紹介元を追加

1. **＋** → **Text** → 名前: `紹介元`

> 紹介元が限定的な場合は **Select** 型にし、選択肢を固定化:

```
智紀さん知人
既存顧客紹介
Web問合せ
チラシ
その他
```

### Step 6: 対応エリアを追加

1. **＋** → **Select** を選ぶ前に **Multi-select** を選択
2. 名前: `対応エリア`
3. 選択肢を追加（§2.3 参照）

### Step 7: 注意事項を追加

1. **＋** → **Text**
2. 名前: `注意事項`
3. 長文入力可（請求書送付先の注意、現場入館方法など）

### Step 8: 過去案件数を追加

1. **＋** → **Rollup**
2. 名前: `過去案件数`
3. Relation: `関連案件`
4. Property: `案件名`
5. Calculate: **Count all**

### Step 9: 列の表示順を整理

推奨順（左から）:

```
顧客名 | 顧客ランク | 顧客区分 | 単価補正率 | 年間売上 | 過去案件数 | 最終工事日 | 紹介元 | 対応エリア | 注意事項 | 請求締日 | 支払条件 | 備考
```

列ヘッダーを **ドラッグ** で並べ替え。

### Step 10: ビューを追加

#### 10-1. ランク別一覧

1. **＋ Add a view** → **Table** → 名前: `ランク別`
2. **Filter** なし
3. **Sort** → `顧客ランク` Ascending → `年間売上` Descending

#### 10-2. Aランク顧客

1. **＋ Add a view** → **Table** → 名前: `Aランク`
2. **Filter** → `顧客ランク` **is** `A`

#### 10-3. 休眠顧客（フォロー対象）

1. **＋ Add a view** → **Table** → 名前: `休眠顧客`
2. **Filter**:
   - `最終工事日` **is before** `6 months ago`（Relative date）
   - OR `最終工事日` **is empty**
3. **Sort** → `最終工事日` Ascending

#### 10-4. エリア別

1. **＋ Add a view** → **Board**
2. **Group by** → `対応エリア`（Multi-select の場合は最初の値でグループ化）

## 5. 案件管理DB への反映

顧客選択時にランク・注意事項を参照できるよう、案件管理DB に Rollup を追加（任意）:

| 追加プロパティ | 型 | 設定 |
|--------------|-----|------|
| 顧客ランク | Rollup | 顧客名 → 顧客ランク |
| 顧客注意事項 | Rollup | 顧客名 → 注意事項 |

### 手順

1. **案件管理DB** を開く
2. **＋** → **Rollup**
3. Relation: `顧客名`
4. Property: `顧客ランク`
5. Calculate: **Show original**
6. 同様に `注意事項` も追加

> 現場担当者が案件を開いたとき、注意事項がすぐ見える。

---

## 6. 初期データ入力

### 6.1 既存顧客のランク付け

1. **全顧客** ビューを開く
2. 1 行ずつ **顧客ランク** を設定
3. 判断に迷う場合は一旦 **B** → 3 ヶ月後に見直し

### 6.2 年間売上の入力

1. 請求DB から過去 12 ヶ月の税込合計を集計
2. 顧客マスターの **年間売上** に入力
3. 月末に更新（運用ルール）

### 6.3 注意事項のテンプレート

```
【請求】請求書は月末締め翌月末払い。メール送付可。
【現場】オートロックあり。事前に管理室へ連絡必要。
【その他】
```

---

## 7. 運用ルール

| タイミング | 作業 |
|-----------|------|
| 新規顧客登録時 | ランク=B、区分・補正率を設定 |
| 案件完了時 | 最終工事日を確認（Rollup なら自動） |
| 月末 | 年間売上を更新、ランク見直し |
| 四半期 | 休眠顧客ビューでフォローリスト作成 |
